# Accordion

아코디언은 제목을 눌러 내용을 펼치거나 접습니다. 여러 내용을 묶어 두고 필요한 항목만 펼쳐 볼 때 씁니다.

<Canvas of={Showcase.Overview} />

## 언제 사용하나요

| 컴포넌트 | 쓰임 |
| --- | --- |
| `Accordion` | 항목을 묶고 크기와 펼침을 함께 관리합니다. |
| `AccordionItem` | 제목과 내용으로 된 항목 하나. 단독으로도 쓸 수 있습니다. |

## 종류

- 크기는 `Accordion`의 `size`(`md` · `sm`)로 고릅니다. 모든 항목에 같이 적용됩니다.
- 항목에 `description`을 넣으면 제목 아래에 설명이 보입니다.
- 항목 아래 구분선은 기본으로 보이며 `divider={false}`로 숨깁니다.

## 상태

- 마우스를 올리면 배경과 구분선 색이 바뀝니다.
- 펼친 항목은 화살표가 위를 향하고, 제목이 굵어지며 구분선이 진해집니다.
- `disabled`이면 펼칠 수 없고 키보드로도 선택되지 않습니다.
- 키보드로 선택하면 제목 안쪽에 포커스 테두리가 보입니다.

## 사용 방법

<Source
  language="tsx"
  code={`import { Accordion, AccordionItem } from 'platform-design-system';

<Accordion defaultExpandedKeys={['advanced']}>
  <AccordionItem id="basic" title="기본 설정">…</AccordionItem>
  <AccordionItem id="advanced" title="고급 설정" description="알림과 수집 조건을 설정합니다.">…</AccordionItem>
  <AccordionItem id="lab" title="실험 기능" disabled>…</AccordionItem>
</Accordion>`}
/>

- 처음에 펼칠 항목은 `defaultExpandedKeys`에 항목의 `id`로 넘깁니다.
- 아코디언은 부모 너비를 채웁니다.

## 접근성

- 제목은 버튼이라 Tab으로 이동하고, Enter 또는 Space로 펼치거나 접습니다. 비활성 항목은 건너뜁니다.
- 제목은 기본으로 `h3` 제목 요소이며, 페이지 구조에 맞게 `headingLevel`로 바꿀 수 있습니다.

## 주의사항

- 기본은 한 번에 한 항목만 펼칩니다. 다른 항목을 펼치면 앞의 항목이 접힙니다.
- 여러 항목을 비교해야 하는 화면에서만 `allowsMultipleExpanded`로 여러 개를 펼칩니다.
- 펼친 항목을 직접 관리하려면 `expandedKeys`와 `onExpandedChange`를 함께 씁니다. 처음 상태만 정하려면 `defaultExpandedKeys`를 씁니다.
- `AccordionItem`을 단독으로 쓸 때는 `expanded` · `defaultExpanded`로 펼침을 정합니다.
