# Accordion — 사용 가이드

Figma **Accordion** 프레임(1035:15645)의 `accordion-item`(10개)을 구현했습니다. 제목 버튼으로 내용을 펼치고 접습니다.

## 사용 예

<Source
  language="tsx"
  code={`import { Accordion, AccordionItem } from 'platform-design-system';

  <AccordionItem id="basic" title="기본 설정">…</AccordionItem>
  <AccordionItem id="advanced" title="고급 설정" description="알림과 수집 조건을 설정합니다.">…</AccordionItem>
  <AccordionItem id="lab" title="실험 기능" disabled>…</AccordionItem>
</Accordion>`}
/>

## 코드 정책 (Figma에서 정해지지 않은 부분)

- **Hover · Expanded 모습**: Hover는 모든 크기에서 배경 `background/hover`와 진한 구분선 `border/hover`, 펼친 항목은 진한 구분선을 씁니다.
  2026-10-19 Figma 갱신을 반영했습니다(이전에는 배경이 sm · Expanded Hover에만 있었음 — F50은 Figma에서 통일되어 해소).
- **Disabled**: 배경 `background/disabled`(fill/disabled), 제목 `title/disabled`(text/placeholder) — 2026-10-19 동기화.
- **여러 개 열기**: Figma에 규칙이 없어 기본은 하나만, `allowsMultipleExpanded`로 여러 개.
- **애니메이션**: 정의가 없어 즉시 펼칩니다.
- **너비**: 부모 너비를 채웁니다(Figma 320px).
