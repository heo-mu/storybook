# Alert

현재 화면에서 알아야 할 상태나 안내를 지속적으로 표시합니다. 일시적인 작업 결과는 Toast를 사용합니다.

<Canvas of={Showcase.Overview} />

## 사용 시점

- 점검 예정 · 업로드 실패처럼 지금 화면의 상태를 설명할 때 씁니다.
- 알림에는 닫기 버튼이 없습니다. 사용자가 닫아야 하는 메시지는 토스트(Toast)를 씁니다.

## 종류

| `status` | 쓰임 |
| --- | --- |
| `information` | 안내 |
| `success` | 성공 |
| `warning` | 주의 — 작업은 계속할 수 있지만 확인이 필요할 때 |
| `error` | 오류 — 작업을 막는 문제 |

- 종류마다 아이콘과 색이 다릅니다. 아이콘은 `showIcon={false}`로 숨길 수 있습니다.
- 제목(`title`)만 쓰거나 설명(`description`)을 더할 수 있습니다.
- 필요한 동작은 `action`에 버튼으로 넣습니다. 버튼은 `Button`의 `tertiary` · `outline` · `xs`를 씁니다.

## 사용 예시

<Source
  language="tsx"
  code={`import { Alert, Button } from 'platform-design-system';

<Alert status="information" title="점검 예정" description="7월 30일 02:00 – 04:00에 서비스를 점검합니다." />

<Alert
  status="error"
  title="업로드 실패"
  description="파일 크기를 확인하세요."
  action={<Button variant="tertiary" appearance="outline" size="xs" onClick={retry}>재시도</Button>}
/>`}
/>

- 알림은 부모 너비를 채웁니다.
- 설명이 길면 줄을 바꿔 모두 보여 줍니다. 되도록 문구를 짧게 씁니다.

## 접근성

- `error` 알림은 화면 낭독기가 바로 읽습니다(`role="alert"`).
- `information` · `success` · `warning` 알림은 `role="status"`로 읽힙니다. 필요하면 `role`로 바꿀 수 있습니다.
