# Badge

배지는 상태나 개수를 짧게 알려 주는 표시입니다. 보여 주기만 하며 누를 수 없습니다.

<Canvas of={Showcase.Overview} />

## 언제 사용하나요

| 컴포넌트 | 쓰임 |
| --- | --- |
| `Badge` | 완료 · 점검 필요처럼 상태를 글자로 알릴 때 |
| `BadgeDot` | 새 글처럼 글자 없이 점 하나로 알릴 때 |
| `BadgeCount` | 읽지 않은 알림처럼 개수를 알릴 때 |

## 종류

<Canvas of={Showcase.StatusMatrix} />

- 색은 `status`로 고릅니다: `basic` · `gray` · `point` · `success` · `warning` · `danger` · `information`. 세 컴포넌트가 같은 값을 씁니다.
- `appearance`로 채운 모양(`filled`)과 테두리 모양(`outline`)을 고릅니다. 테두리 모양은 배경이 없습니다.
- 크기는 `size`(`sm` · `md` · `lg`), 모서리는 `shape`(`square` · `rounded`)로 고릅니다.
- `Badge` 앞의 점은 `dot={false}`로 숨길 수 있습니다.
- `BadgeCount`는 `max`(기본 99)보다 큰 수를 "99+"처럼 줄여 보여 줍니다.

## 사용 방법

<Source
  language="tsx"
  code={`import { Badge, BadgeDot, BadgeCount } from 'platform-design-system';

<Badge status="success">완료</Badge>
<Badge status="warning" appearance="outline" shape="rounded" size="md">점검 필요</Badge>
<Badge status="information" dot={false}>안내</Badge>

<BadgeDot status="point" aria-label="새 글" />
<BadgeCount count={unread} status="point" aria-label={\`읽지 않은 알림 \${unread}개\`} />`}
/>

## 접근성

- `Badge`의 글자는 화면 낭독기가 그대로 읽습니다.
- `BadgeDot`은 꾸밈으로 처리되어 읽히지 않습니다. 뜻이 있는 점이면 `aria-label`을 붙입니다.
- `BadgeCount`의 숫자만으로 뜻이 부족하면 `aria-label`로 설명합니다(예: "읽지 않은 알림 7개").
- 색만으로 뜻을 전하지 않도록 글자나 `aria-label`을 함께 씁니다.
