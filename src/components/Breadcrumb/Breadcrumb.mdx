# Breadcrumb

Breadcrumb는 지금 페이지가 어디에 있는지 홈부터 이어지는 경로로 보여 줍니다. 경로의 각 단계를 눌러 상위 페이지로 이동할 수 있습니다.

<Canvas of={Showcase.Overview} />

## 언제 사용하나요

- 메뉴 단계가 깊은 화면에서 지금 위치를 알려 줄 때 씁니다.
- 경로의 맨 앞은 홈 아이콘이고, 맨 끝은 지금 페이지입니다.

## 종류

| `layout` | 모양 |
| --- | --- |
| `full` (기본) | 홈부터 지금 페이지까지 경로를 모두 보여 줍니다 |
| `collapsed` | 홈 · … · 상위 페이지 · 지금 페이지만 보여 주고, 나머지 경로는 … 메뉴에 넣습니다 |

- 크기는 `size`(`md` · `sm`)로 고릅니다. 기본은 `md`입니다.
- `collapsed`에서 `showParent`를 끄면 상위 페이지도 … 메뉴로 들어갑니다.
- `full`은 경로가 끊기지 않도록 항상 전체 경로를 보여 줍니다. `showParent`는 `collapsed`에만 적용됩니다.

## 상태

<Canvas of={Showcase.ItemMatrix} />

- 마우스를 올리거나 누르면 항목의 모양이 바뀝니다.
- 지금 페이지 항목은 강조된 모양이고, 누를 수 없습니다.
- 키보드로 선택하면 포커스 테두리가 보입니다.

## 사용 방법

<Source
  language="tsx"
  code={`import { Breadcrumb } from 'platform-design-system';

<Breadcrumb
  homeHref="/"
  items={[
    { label: '에너지 관리', href: '/energy' },
    { label: '에너지 절약', href: '/energy/saving' },
    { label: '프로그램 목록', href: '/energy/saving/programs' },
  ]}
  current="프로그램 등록"
/>

// 경로가 길면 접습니다 — 홈 · … · 상위 페이지 · 지금 페이지
<Breadcrumb layout="collapsed" items={items} current="프로그램 등록" />`}
/>

- `items`에는 맨 위 단계부터 지금 페이지의 바로 위 페이지까지 순서대로 넣습니다.
- 지금 페이지 이름은 `current`로 넘깁니다.
- `href`가 없는 경로는 버튼이 되고, 누르면 `onAction`이 그 경로의 `id`로 호출됩니다.
- … 메뉴는 버튼 바로 아래에 [DropdownMenu](?path=/docs/components-dropdownmenu-usage--docs)로 열립니다.

## 접근성

- 화면 낭독기는 전체를 "이동 경로" 영역으로 읽습니다. 다른 이름이 필요하면 `aria-label`로 바꿉니다.
- 홈은 아이콘만 보이고, 화면 낭독기는 "홈"으로 읽습니다. 다른 말은 `homeLabel`로 바꿉니다.
- … 버튼은 "중간 경로 보기"로 읽습니다. 다른 말은 `moreLabel`로 바꿉니다.
- 지금 페이지는 화면 낭독기에 현재 페이지로 알려집니다.
