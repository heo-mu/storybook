# Breadcrumb — 사용 가이드

Figma **Breadcrumb** 프레임(721:13374)의 `breadcrumb`(6개) · `breadcrumb-item`(12개) · `breadcrumb-modern-separator`를 구현했습니다.
접힌 경로의 메뉴는 [Dropdown Menu](?path=/docs/components-dropdownmenu-usage--docs)를 사용합니다.

<Canvas of={Showcase.Overview} />

## 사용 예

<Source
  language="tsx"
  code={`import { Breadcrumb } from 'platform-design-system';

<Breadcrumb
  homeHref="/"
  items={[
    { label: '에너지 관리', href: '/energy' },
    { label: '에너지 절약', href: '/energy/saving' },
    { label: '프로그램 목록', href: '/energy/saving/programs' },
  ]}
  current="프로그램 등록"
/>

// 경로가 길면 접기 — 홈 · … · 상위 페이지 · 현재 페이지
<Breadcrumb layout="collapsed" items={items} current="프로그램 등록" />`}
/>

## Figma 속성 → Props

| Figma | Prop | 비고 |
| --- | --- | --- |
| Size md · sm | `size` | 높이 32 · 28px |
| Layout Full · Collapsed | `layout` | Collapsed: 중간 경로를 … 메뉴로 |
| Expanded | `expanded` / `defaultExpanded` / `onExpandedChange` | … 메뉴 열림 |
| Show Parent | `showParent` | Collapsed에서 상위 페이지 표시 |
| Home (House 아이콘) | `homeHref` · `homeLabel` | 아이콘만 표시, 이름 "홈" |
| item Role Link · Current · Open | `BreadcrumbItem` `href` · `current` · `open` | |
| item State Hover · Pressed | 브라우저 `:hover` · `:active` | |
| item Show Icon · Show Label | `icon` · `children` | 아이콘만 쓰면 `aria-label` 필요 |

## 코드 정책 (Figma에서 정해지지 않은 부분)

- **펼친 상태(Expanded)**: Figma는 메뉴가 열린 동안 현재 페이지 항목을 Role=Open(브랜드 색)으로, 메뉴를 경로 오른쪽 끝에 맞춰
  그렸습니다. 메뉴를 여는 것은 … 버튼이므로 코드는 메뉴를 … 버튼 아래(2px)에 열고, 현재 페이지는 Current 그대로 둡니다
  (figma-issues F33 — 결정 필요). Role=Open은 `BreadcrumbItem open`으로 쓸 수 있습니다.
- **아이콘 상태 색**: Figma는 Link Default에만 아이콘이 있어, Hover · Pressed · Current에서는 같은 이름의 Figma 변수
  (`breadcrumb/home-icon/hover` · `pressed` · `current`)를 씁니다 (F34).
- **Show Parent**: Collapsed에만 적용합니다. Full에서 상위 페이지를 숨기면 경로가 끊기기 때문입니다.
- **메뉴 너비**: Figma 메뉴 프레임 너비 200px, 더 긴 이름은 넓어집니다.
- **포커스 표시**: Figma에 Focus 상태가 없어 브라우저 기본 포커스 링을 사용합니다.
