# Button

저장·조회·다음 단계 이동 등 사용자 동작을 실행합니다. 동작의 중요도에 맞춰 종류를 선택합니다.

<Canvas of={OverviewStories.Overview} />

## 사용 시점

| 컴포넌트 | 쓰임 |
| --- | --- |
| `Button` | 저장 · 조회 · 다음처럼 글자로 행동을 알려 주는 버튼 |
| `IconButton` | 추가 · 닫기 · 새로고침처럼 아이콘만으로 뜻이 분명한 버튼 |
| `TextButton` | 더보기처럼 배경 없이 글자로만 보이는 가벼운 버튼 |

## 종류

| `variant` | 쓰임 |
| --- | --- |
| `primary` | 가장 강조할 행동 |
| `secondary` | 보조 행동 |
| `tertiary` | 덜 강조할 행동 |

- `appearance`로 채운 모양(`solid`)과 테두리 모양(`outline`)을 고릅니다. 지정하지 않으면 Secondary는 테두리 모양, 나머지는 채운 모양입니다.
- 크기는 `size`(`xs` · `sm` · `md` · `lg`), 모서리는 `shape`(`square` · `rounded`)로 고릅니다.
- `TextButton`은 `primary` · `secondary` 두 종류와 `sm` · `md` 크기가 있습니다.

## 상태

<Canvas of={StatesStories.ButtonStates} />

- Secondary / Solid는 Hover와 Pressed에서 배경이 같은 초록 계열 안에서 한 단계씩 밝아져요(기본 brand/700 → Hover brand/600 → Pressed brand/500, Primary / Solid와 같은 방향). 라벨과 아이콘은 Default와 같은 흰색을 유지해요. Button과 IconButton에 동일하게 적용돼요.
- 흰 글자 대비율은 Default 5.14:1, Hover 3.51:1, Pressed 2.46:1이에요. Hover와 Pressed는 WCAG AA 글자 기준(4.5:1)에 못 미치고, Pressed는 아이콘 기준(3:1)에도 못 미쳐요. 상태가 진행될수록 밝아지는 디자인을 우선한 결정이에요.
- 마우스를 올리거나 누르면 모양이 바뀝니다.
- `disabled`이면 누를 수 없고 키보드 포커스를 받지 않습니다.
- 키보드 포커스를 받으면 포커스 테두리가 보입니다.
- 저장처럼 시간이 걸리는 동작은 끝날 때까지 버튼을 `loading`으로 바꿉니다(Figma Form 사용 예시 "저장 중"). 글자 자리에 16px 회전 표시가 보이고 버튼의 크기 · 색은 그대로이며, 다시 누르거나 Enter · Space를 눌러도 실행되지 않습니다. 포커스는 유지되고 화면 낭독기에는 `loadingLabel`(기본 "처리 중")이 상태로 전달됩니다. 끝나면 `loading`을 끄고 완료 · 실패 메시지를 보여 줍니다.

## 아이콘

- `leftIcon` · `rightIcon` · `icon`에 아이콘 요소를 넘기면 버튼 크기에 맞게 표시됩니다.
- 아이콘은 텍스트 색을 따르므로 SVG에 `fill="currentColor"`를 씁니다.

## 접근성

- 아이콘만 있는 `IconButton`에는 `aria-label`로 이름을 꼭 붙입니다.
- 버튼 안의 아이콘은 꾸밈으로 처리되어 화면 낭독기가 읽지 않습니다.
