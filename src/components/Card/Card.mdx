# Card

카드는 관련된 내용과 버튼을 한 상자로 묶어 보여 줍니다. 머리글 · 본문 · 바닥글을 조합해 만듭니다.

<Canvas of={CardStories.Playground} />

## 언제 사용하나요

| 컴포넌트 | 쓰임 |
| --- | --- |
| `Card` | 카드 상자. 안에 아래 부분을 넣습니다. |
| `CardHeader` | 제목 · 설명 · 오른쪽 버튼 |
| `CardContent` | 본문 내용 |
| `CardFooter` | 아래쪽 버튼. 버튼이 너비를 나눠 채웁니다. |

- 필요한 부분만 넣습니다. 예를 들어 바닥글 없이 머리글과 본문만 써도 됩니다.

## 사용 방법

<Source
  language="tsx"
  code={`import { Button, Card, CardHeader, CardContent, CardFooter } from 'platform-design-system';

<Card>
  <CardHeader title="이번 달 사용량" description="10월 1일 – 16일"
    action={<Button variant="tertiary" appearance="outline" size="sm">상세</Button>} />
  <CardContent>…</CardContent>
  <CardFooter>
    <Button size="md">보고서 보기</Button>
    <Button variant="tertiary" appearance="outline" size="md">닫기</Button>
  </CardFooter>
</Card>`}
/>

## 접근성

- 카드 제목은 제목 요소(기본 `<h3>`)입니다. 페이지 구조에 맞게 `headingLevel`로 바꿉니다.

## 주의사항

- 카드는 부모 너비를 채웁니다. 너비는 카드를 감싼 영역에서 정합니다.
- 설명이 길면 줄바꿈되며 잘리지 않습니다.
