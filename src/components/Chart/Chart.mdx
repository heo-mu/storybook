# Chart

수치의 추이와 항목 간 차이를 선 또는 막대 차트로 보여 줍니다. 툴팁으로 개별 값을 확인할 수 있습니다.

<Canvas of={ChartStories.Playground} />

## 사용 시점

| 컴포넌트 | 쓰임 |
| --- | --- |
| `Chart` | 차트 전체. 범례와 툴팁도 함께 그립니다. |
| `ChartLegendItem` | 차트 밖에 범례를 따로 만들 때 |
| `ChartTooltip` | 차트 툴팁 모양을 따로 쓸 때 |

## 종류

| `type` | 모양 |
| --- | --- |
| `bar-vertical` | 세로 막대 차트(기본) |
| `bar-horizontal` | 가로 막대 차트 |
| `line` | 선 차트 |

| `variant` | 모양 |
| --- | --- |
| `default` | 축 이름 · 값 눈금 · 범례가 있는 기본 차트 |
| `simple` | 축과 범례를 생략한 160px 높이의 차트 |

<Canvas of={ChartStories.Simple} />

- `categories`에 항목 이름을, `series`의 `data`에 항목 순서대로 값을 넣습니다.
- `series`에는 계열을 1개 또는 2개 넣습니다. 두 번째 계열은 비교 계열이고, 세 번째부터는 표시하지 않습니다.
- 기본 차트의 축 이름은 `yAxisLabel` · `xAxisLabel`, 값 눈금은 `ticks`로 정합니다. `ticks`가 없으면 0부터 4칸으로 나눕니다.
- 기본 스타일 선 차트는 첫 계열의 가장 큰 값에 "최고" 배지를 붙입니다. `maxLabel={false}`로 숨깁니다.

## 상태

- `highlightedIndex`는 툴팁 없이 선택 영역의 배경만 강조합니다. 선·막대와 비교 계열의 색상은 유지합니다.
- Hover 또는 키보드 탐색 중에는 탐색 중인 항목을 우선 표시하고, 탐색을 마치면 지정한 강조 위치로 돌아옵니다.
- 마우스를 올리면 가장 가까운 항목이 강조되고 툴팁에 값이 보입니다. 선 차트는 안내선과 빈 원, 막대 차트는 강조 영역으로 표시합니다.
- 터치 화면에서는 탭한 항목이 표시되고, 차트 밖을 누르면 닫힙니다.
- 툴팁은 차트 안에 표시됩니다. 오른쪽 공간이 모자라면 왼쪽에 표시됩니다.
- 키보드 포커스를 받으면 그림 영역에 포커스 테두리가 보입니다.

## 색

- 첫 계열은 브랜드 색, 두 번째 계열은 구분되는 다른 색으로 그립니다.
- Simple을 포함한 모든 스타일에서 같은 계열의 색상은 동일합니다. 선택 상태는 색상 변경 대신 배경으로 구분합니다.
- 색은 차트 전용 토큰(`colors/chart/*`)을 씁니다.

<Chart variant="simple" type="line" aria-label="월별 사용량"

## 접근성

- 차트에는 `aria-label`로 이름을 붙입니다.
- 그림은 화면 낭독기가 읽지 않는 대신, 모든 값을 화면 낭독기용 표로 제공합니다. 표의 제목은 `aria-label`입니다.
- 그림 영역은 키보드로 포커스를 이동할 수 있습니다. ← → (↑ ↓)로 항목을 옮기고, Home · End로 처음 · 마지막 항목, Esc로 툴팁을 닫습니다.
- 키보드로 옮긴 항목의 값은 화면 낭독기가 읽어 줍니다. 그림 영역의 이름은 `plotLabel`로 바꿀 수 있습니다.

## 사용 규칙

- 0 이상의 값만 지원합니다. 눈금 범위를 벗어난 값은 범위 끝에 그립니다.
- 차트 너비는 감싼 영역에 맞춰집니다.
- 툴팁 항목을 직접 정하려면 `activeIndex`와 `onActiveIndexChange`를 함께 씁니다. `null`이면 툴팁을 숨깁니다. 초깃값만 정하려면 `defaultActiveIndex`를 씁니다.
