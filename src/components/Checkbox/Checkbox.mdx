# Checkbox

독립적인 옵션을 선택하거나 여러 옵션을 함께 선택할 때 사용합니다. CheckboxGroup으로 선택값을 함께 관리할 수 있습니다.

<Canvas of={Showcase.Overview} />

## 사용 시점

| 컴포넌트 | 쓰임 |
| --- | --- |
| `Checkbox` | 약관 동의처럼 하나를 켜고 끄거나, 옵션을 여러 개 고를 때 |
| `CheckboxGroup` | 여러 체크박스를 묶어 선택한 값 목록을 한 번에 관리할 때 |

## 종류

- 선택은 `checked` · `defaultChecked`로 정합니다. 일부만 선택된 상태는 `indeterminate`로 표시합니다.
- 크기는 `size`(`sm` · `md` · `lg`)로 고릅니다. 기본은 `sm`이고, 그룹 안에서는 그룹의 `size`를 따릅니다.
- `label`을 빼면 상자만 보입니다.

## 상태

<Canvas of={Showcase.States} />

- 마우스를 올리거나 누르면 모양이 바뀝니다. 라벨 위에서도 똑같이 동작합니다.
- `disabled`이면 누를 수 없고 키보드 포커스를 받지 않습니다.
- 키보드 포커스를 받으면 상자 둘레에 포커스 테두리가 보입니다.

## 사용 예시

<Source
  language="tsx"
  code={`import { Checkbox, CheckboxGroup } from 'platform-design-system';

<Checkbox label="이용약관 동의" name="terms" required />

// 제어 컴포넌트
<Checkbox label="자동 로그인" checked={remember} onChange={(e) => setRemember(e.target.checked)} />

// 전체 선택 (일부만 선택되면 일부 선택 표시)
<Checkbox label="전체" checked={all} indeterminate={some && !all} onChange={toggleAll} />

// 그룹 — 선택된 value 배열을 관리
<CheckboxGroup aria-label="수신 채널" value={channels} onChange={setChannels} name="channel">
  <Checkbox value="email" label="이메일" />
  <Checkbox value="sms" label="SMS" />
</CheckboxGroup>`}
/>

## CheckboxGroup

- `value`가 있는 체크박스들의 선택값을 배열로 관리합니다. `value` · `onChange`로 직접 관리하거나 `defaultValue`로 초깃값만 정합니다.
- `name` · `size` · `disabled`를 주면 그룹 안의 모든 체크박스에 적용됩니다.
- `orientation`으로 세로(`vertical`, 기본) 또는 가로(`horizontal`) 배치를 고릅니다. 항목 사이 간격은 자동으로 맞춰집니다.

## 그룹 오류

<Canvas of={Showcase.GroupMessage} />

- 필수 항목이 선택되지 않았으면 `invalid`와 `message`로 그룹 아래에 오류 메시지를 보여 줍니다. 체크박스 색은 바뀌지 않습니다.
- 필수 동의처럼 체크박스가 하나여도 `CheckboxGroup`으로 감싸 오류 메시지를 붙입니다.
- `invalid` 없이 `message`만 넣으면 회색 도움말로 보입니다.
- 화면 낭독기는 각 체크박스를 오류 상태로 알리고 메시지를 설명으로 읽습니다.

<Source
  language="tsx"
  code={`<CheckboxGroup aria-label="약관 동의" value={agreed} onChange={setAgreed}
  invalid={submitted && !agreed.includes('privacy')} message={submitted && !agreed.includes('privacy') ? '개인정보 수집 · 이용에 동의해야 저장할 수 있습니다.' : undefined}>
  <Checkbox value="privacy" label="개인정보 수집 · 이용에 동의합니다" />
</CheckboxGroup>`}
/>

## 접근성

- `label`이 없는 체크박스에는 `aria-label`로 이름을 꼭 붙입니다.
- `CheckboxGroup`에는 `aria-label` 또는 `aria-labelledby`로 그룹 이름을 붙입니다.
- Space 키로 선택하거나 해제합니다. 일부 선택 상태는 화면 낭독기에 "일부 선택"으로 전달됩니다.

## 사용 규칙

- 일부 선택 상태에서 누르면(클릭 · Space) 해제됩니다 — 전체 선택 체크박스라면 하위 항목이 모두 해제됩니다. `onChange`의 `e.target.checked`는 `false`로 전달되므로, 제어 컴포넌트는 그 값으로 하위 항목과 `indeterminate`를 다시 계산합니다.
- 나머지 `<input>` 속성과 `ref`는 실제 체크박스에 전달되고, `className` · `style`은 라벨을 포함한 바깥 요소에 적용됩니다.
