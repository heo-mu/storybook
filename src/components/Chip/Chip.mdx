# Chip

필터 선택, 입력된 태그 삭제, 옵션 목록 열기에 사용하는 컴포넌트입니다. 목적에 따라 Chip·InputChip·FilterChip·FilterChipSelect를 선택합니다.

<Canvas of={Showcase.Overview} />

## 사용 시점

| 컴포넌트 | 쓰임 |
| --- | --- |
| `Chip` | 여러 개를 켜고 끄는 필터 |
| `InputChip` | 입력한 값(태그)을 보여 주고 지울 수 있는 칩 |
| `FilterChip` | 필터 메뉴나 패널을 여는 칩. 메뉴는 직접 연결합니다 |
| `FilterChipSelect` | 필터 칩과 옵션 목록이 함께 있는 완성된 필터 |

## 종류

- 크기는 `size`(`xs` · `sm` · `md`)로 고릅니다. 기본은 `xs`이고, `FilterChipSelect`만 `md`입니다.
- `Chip`은 선택되면 글자 뒤에 체크 아이콘이 붙습니다.
- `InputChip`은 글자 뒤에 지우기(X) 아이콘이 붙습니다.
- `FilterChip`은 글자 뒤에 화살표가 붙고, 펼치면 위쪽 화살표로 바뀝니다.

## 상태

<Canvas of={Showcase.States} />

- 마우스를 올리거나 누르면 모양이 바뀝니다.
- `selected`이면 선택 상태입니다. 필터 칩에서는 값이 적용되었다는 뜻이며, 테두리와 글자가 브랜드 색이 됩니다.
- `expanded`이면 필터 칩이 펼침 모양이 됩니다.
- `FilterChipSelect`의 목록은 짧게 나타나며 열리고, 닫을 때도 짧게 사라집니다. 동작 줄이기를 켜면 바로 열리고 닫힙니다.
- `disabled`이면 누를 수 없습니다.
- 키보드 포커스를 받으면 포커스 테두리가 보입니다.

## 사용 예시

### Chip · InputChip · FilterChip

<Source
  language="tsx"
  code={`import { Chip, InputChip, FilterChip } from 'platform-design-system';

// 여러 개를 고르는 필터
<div role="group" aria-label="상태">
  {statuses.map((s) => (
    <Chip key={s} size="sm" selected={selected.includes(s)} onSelectedChange={(on) => toggle(s, on)}>{s}</Chip>
  ))}
</div>

// 입력한 태그
{tags.map((t) => <InputChip key={t} size="sm" onRemove={() => remove(t)}>{t}</InputChip>)}

// 필터 메뉴를 여는 칩 (MenuTrigger 안에서는 펼침 상태와 화살표가 자동으로 바뀝니다)
<MenuTrigger>
  <FilterChip size="sm" selected={!!owner}>{owner ? \`담당자: \${owner}\` : '담당자'}</FilterChip>
  <Popover>…</Popover>
</MenuTrigger>`}
/>

- 칩 여러 개는 `role="group"`과 `aria-label`로 묶습니다.
- 칩 사이 간격은 `gap: var(--spacing-margin-m-1)`로 줍니다. 줄이 바뀌어도 같은 간격을 씁니다.

### FilterChipSelect

칩을 누르면 칩 아래에 옵션 목록이 열립니다. 필터를 적용하면 칩이 강조되고 글자가 선택 개수에 따라 바뀝니다 — 0개 "필터명", 1개 "필터명: 값", 2개 이상 "필터명: 첫 값 외 n개"(예: 지역 → 지역: 서울 → 지역: 서울 외 1개 → 지역: 서울 외 2개). 첫 값은 옵션 목록 순서 기준이고, 선택을 바꾸면 즉시 갱신됩니다. 이름을 더 나열하려면 `maxDisplayed`를 늘립니다.

| 선택 방식 | 쓰임 | 동작 |
| --- | --- | --- |
| 다중 선택(`selectionMode="multiple"`, 기본) | 동 · 설비 종류처럼 여러 값으로 거르는 필터 | 목록이 열린 채로 옵션을 켜고 끕니다. 목록을 닫을 때 적용됩니다. 모든 옵션을 해제하고 닫으면 필터가 초기화됩니다. |
| 단일 선택(`selectionMode="single"`) | 기간 · 상태처럼 하나만 고르는 필터 | 고르면 바로 적용되고 목록이 닫힙니다. 첫 옵션 "전체"(`clearLabel`)를 고르면 필터가 초기화됩니다. |

## 접근성

- `InputChip`은 칩 전체가 지우기 버튼입니다. Enter · Space · Delete · Backspace로도 지울 수 있습니다.
- 화면 낭독기는 `InputChip`을 "라벨 삭제"로 읽습니다. 다른 말이 필요하면 `removeLabel`로 바꿉니다.
- `FilterChipSelect`는 Enter · Space · ↓로 목록을 열고, 방향키나 글자 입력으로 옵션을 옮깁니다.
- `FilterChipSelect`는 Space · Enter로 옵션을 고르고, Esc로 닫습니다. 닫으면 키보드 위치가 칩으로 돌아옵니다.
- 화면 낭독기는 필터 칩을 지금 보이는 글자("동: 101동, 103동")로 읽습니다.

## 사용 규칙

- `Chip`에 `selected`를 넘기면 선택 상태를 바깥에서 관리합니다. 넘기지 않으면 `defaultSelected`로 시작해 칩이 스스로 관리합니다.
- `FilterChipSelect`의 여러 개 고르기는 목록을 닫을 때(Esc · 바깥 누르기 · 칩 누르기) 한 번만 `onChange`를 호출합니다.
- `FilterChip`은 `MenuTrigger` · `DialogTrigger` 안에서만 펼침 상태가 자동으로 바뀝니다. 그 밖에서는 `expanded`를 직접 넘깁니다.
