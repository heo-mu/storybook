# DashboardFilterBar

대시보드의 조회 조건과 실행 버튼을 한곳에 배치합니다. 조건을 그룹으로 구성할 수 있습니다.

<Canvas of={FilterBarStories.Playground} />

## 사용 시점

- 대시보드에서 조회 대상 · 조회 기간 같은 조건을 고른 뒤 조회할 때 씁니다.
- 조건 컨트롤은 디자인 시스템의 Select · FilterChip · SegmentedControl을 `size="sm"`으로 넣습니다.

## 구성

| 컴포넌트 | 쓰임 |
| --- | --- |
| `DashboardFilterBar` | 조회 조건 막대. 오른쪽 버튼은 `actions`에 넣습니다. |
| `DashboardFilterGroup` | 라벨이 붙은 조건 묶음. 묶음 사이에는 구분선이 자동으로 들어갑니다. |
| `DashboardFilterRange` | 두 컨트롤을 "~"로 잇습니다(예: 시작일 ~ 종료일). |

- 디자인 예시의 초기화 버튼은 `IconButton variant="secondary" appearance="solid"`입니다.
- 화면이 좁으면 묶음 단위로 다음 줄로 넘어갑니다.

<Canvas of={FilterBarStories.Narrow} />

## 사용 예시

<Source
  language="tsx"
  code={`import { Button, DashboardFilterBar, DashboardFilterGroup, DatePicker, Select, SelectOption } from 'platform-design-system';

<DashboardFilterBar actions={<Button size="md">조회</Button>}>
  <DashboardFilterGroup label="조회 대상">
    <Select size="sm" aria-label="조회 대상" defaultValue="all"><SelectOption id="all">전체 단지</SelectOption></Select>
  </DashboardFilterGroup>
  <DashboardFilterGroup label="조회 기간">
    <DatePicker selectionMode="range" aria-label="조회 기간" />
  </DashboardFilterGroup>
</DashboardFilterBar>`}
/>

## 접근성

- 막대는 검색 영역으로 읽히고, 이름은 기본 "조회 조건"입니다. `aria-label`로 바꿀 수 있습니다.
- 각 묶음은 `label`을 이름으로 읽힙니다.
- 컨트롤에는 보이는 라벨이 없으므로 컨트롤마다 `aria-label`을 꼭 붙입니다.
- 구분선과 "~"는 꾸밈으로 처리되어 화면 낭독기가 읽지 않습니다.
