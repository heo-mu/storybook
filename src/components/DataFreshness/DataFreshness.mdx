# DataFreshness

데이터가 얼마나 최신인지 상태 배지, 마지막 수신 시각, 갱신 주기로 보여 줍니다.

<Canvas of={Showcase.Figma} />

## 언제 사용하나요

- 대시보드 같은 데이터 화면에서 데이터를 언제 받았는지, 지금 잘 들어오고 있는지 알려 줄 때 씁니다.

## 상태

| `state` | 배지 글자(기본) | 배지 |
| --- | --- | --- |
| `fresh` | 최근 수신 | 성공 배지 |
| `stale` | 수신 지연 | 경고 배지 |
| `offline` | 연결 끊김 | 회색 배지 |

- 배지 글자는 `label`로 바꿀 수 있습니다.
- `timestamp`에 마지막 수신 시각, `interval`에 갱신 주기를 넣습니다. `interval`은 "·" 뒤에 표시되고, 없으면 생략됩니다.

## 사용 방법

<Source
  language="tsx"
  code={`import { DataFreshness } from 'platform-design-system';

<DataFreshness state="fresh" timestamp="2026.10.14 09:30" dateTime="2026-10-14T09:30" interval="자동 갱신 1분" />`}
/>

## 접근성

- `dateTime`에 표준 형식의 시각을 함께 주면 시각이 `<time>` 요소로 표시됩니다.
- 시각이 바뀔 때마다 화면 낭독기가 읽어 주지는 않습니다. 상태 변화를 알려야 하면 사용하는 화면에서 따로 알립니다.
- 시각과 갱신 주기 사이의 "·"는 화면 낭독기가 읽지 않습니다.
