# DataState

데이터 영역에 내용 대신 보여 주는 안내입니다. 불러오는 중, 빈 상태, 결과 없음, 오류, 권한 없음, 일부만 표시를 알립니다.

<Canvas of={DataStateStories.ErrorState} />

## 언제 사용하나요

- 표나 차트 같은 데이터 영역에 보여 줄 내용이 없거나 아직 준비되지 않았을 때, 그 자리에 둡니다.

## 상태

<Canvas of={Showcase.Figma} />

| `state` | 뜻 | 기본 버튼 |
| --- | --- | --- |
| `loading` | 불러오는 중 | 없음 |
| `empty` | 빈 상태 — 아직 수집된 데이터가 없음 | 수집 설정 확인 |
| `no-results` | 결과 없음 — 조회 조건에 맞는 데이터가 없음 | 조건 초기화 |
| `error` | 오류 — 데이터를 불러오지 못함 | 다시 시도 |
| `no-access` | 권한 없음 | 권한 안내 |
| `partial` | 일부만 표시 — 일부 데이터가 누락됨 | 누락 내역 확인 |

- 상태마다 기본 제목 · 설명 · 버튼 글자가 있습니다. `title` · `description` · `actionLabel`로 바꿀 수 있습니다.
- `description={null}`이면 설명을 숨깁니다.
- `loading`은 스켈레톤 막대와 문구를 보여 줍니다. 문구는 `loadingLabel`로 바꿉니다.

## 사용 방법

<Source
  language="tsx"
  code={`import { DataState } from 'platform-design-system';

{isLoading ? <DataState state="loading" />
  : error ? <DataState state="error" onAction={refetch} />
  : rows.length === 0 ? <DataState state="no-results" onAction={resetFilters} />
  : <Table … />}`}
/>

## 접근성

- 상태가 바뀌면 화면 낭독기가 새 문구를 읽어 줍니다.
- 스켈레톤과 아이콘은 꾸밈으로 처리되어 화면 낭독기가 읽지 않습니다.

## 주의사항

- 버튼은 `onAction`(또는 `action`)을 넘길 때만 나타납니다. 할 일이 없으면 버튼을 두지 않습니다.
- `partial`에는 기본 설명이 없습니다. 실제 수치를 `description`으로 넣습니다.
- 너비는 부모를 채웁니다.
