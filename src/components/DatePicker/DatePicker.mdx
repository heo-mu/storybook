# DatePicker

날짜 또는 기간을 선택해요. 날짜 필드를 누르면 달력이 열리는 `input` 방식과, 달력만 보여 주는 `inline` 방식이 있어요.

<Canvas of={Showcase.Overview} />

## 사용 시점

- 입력 화면의 한 칸으로 날짜를 받을 때는 `input`을 써요. Select와 같은 모양의 필드이고, 오른쪽에 달력 아이콘이 있어요.
- 화면에 달력을 항상 펼쳐 두고 싶을 때는 `variant="inline"`을 써요. 기존 Calendar와 같은 달력이에요.
- 필드에 직접 글자를 입력하지는 않아요. 필드는 달력을 여는 버튼이고, 값은 달력에서 골라요.

## Input

- 필드나 달력 아이콘을 누르면 필드 아래에 달력이 열려요. 아래 공간이 없으면 위로 열려요.
- 날짜를 고르면 필드에 `2026.10.28`처럼 표시되고 달력이 닫혀요. 기간은 시작일과 종료일을 고르면 `2026.10.28 ~ 2026.11.03`으로 표시되고 닫혀요.
- 비어 있을 때는 `YYYY.MM.DD`(기간은 `YYYY.MM.DD ~ YYYY.MM.DD`)가 보여요. `placeholder`로 바꿀 수 있어요.
- Esc를 누르거나 바깥을 누르면 고르지 않고 닫혀요. 닫히면 포커스는 필드로 돌아와요.
- 비활성 필드는 누르거나 키보드로 열 수 없고, 읽기 전용 필드는 값만 보여 줘요(달력 아이콘 없음).
- 필드는 `sm` · `md` · `lg` 크기가 있고 라벨 · 도움말 · 오류 메시지 · 필수 표시는 Input, Select와 같은 규칙이에요.

## Single / Range

- Single은 날짜 하나를 선택해요.
- Range는 시작일을 누른 뒤 종료일을 눌러요. 앞선 날짜를 두 번째로 선택하면 날짜 순서대로 정렬해요.
- 같은 날짜를 두 번 선택하면 하루짜리 기간이 돼요. 완성된 기간에서 다시 날짜를 누르면 새 선택을 시작해요.
- 시작일 선택 후 마우스를 올리거나 키보드로 이동하면 임시 범위가 보여요. 두 번째 선택 전에는 값이 확정되지 않아요.
- 비활성 날짜를 포함하는 연속 기간은 선택할 수 없어요. 이전·다음 달로 이동해 여러 달에 걸친 기간을 선택할 수 있어요.

## Year / Month

연도와 월을 각각 선택해 이동해요. 연도를 바꾸면 현재 월을 유지하고, 그 월이 제한 범위를 벗어나면 선택 가능한 가장 가까운 월로 이동해요.

연도 목록은 표시 연도 전후 10년을 제공해요. 다른 연도를 선택하면 목록도 그 연도를 중심으로 이동해요. `minValue` / `maxValue` 밖의 연도·월과 선택할 수 있는 날짜가 없는 연도·월은 목록에서 제외해요. 월 이동 버튼으로도 계속 탐색할 수 있어요.

## Keyboard

| 위치 | 키 | 동작 |
| --- | --- | --- |
| 필드 | Enter / Space / ↓ | 달력 열기(포커스는 선택된 날짜 또는 오늘로 이동) |
| 달력 | Escape | 고르지 않고 닫기, 포커스는 필드로 |
| 날짜 | ← → / ↑ ↓ | 하루 / 일주일 이동 |
| 날짜 | Home / End | 주의 처음 / 끝 |
| 날짜 | Page Up / Page Down | 이전 / 다음 달 |
| 날짜 | Enter / Space | 날짜 또는 기간 끝 선택(`input`은 선택 후 닫힘) |
| 연도·월 | Enter / Space / ↓ | 목록 열기 |
| 목록 | ↑ ↓ / Home / End | 항목 탐색 |
| 목록 | Enter / Space | 선택 |
| 목록 | Escape / 외부 클릭 | 닫기 |

## Usage

<Source code={`// 필드 + 달력
<DatePicker label="방문일" value={date} onChange={setDate} />

// 기간
<DatePicker
  label="이용 기간"
  selectionMode="range"
  rangeValue={range}
  onRangeChange={setRange}
  minValue="2026-01-01"
  maxValue="2026-12-31"
/>

// 달력만
<DatePicker variant="inline" aria-label="일정" value={date} onChange={setDate} />`} />

단일 날짜는 ISO 문자열(`'YYYY-MM-DD'`) 또는 null을 사용해요. 기간은 `{ start: 'YYYY-MM-DD', end: 'YYYY-MM-DD' }` 또는 null이에요.
`defaultValue` / `defaultRangeValue`는 비제어 방식의 초깃값이에요. `defaultFocusedValue`로 처음 표시할 달을 지정할 수 있어요.

`disabled`는 전체 조작을 막고, `readOnly`는 날짜 변경만 막아요. `required`는 필수 표시와 접근성 정보를 제공해요.
`name`이 있으면 Single은 해당 이름으로, Range는 `name.start`와 `name.end`로 확정된 날짜를 전송해요. 비활성 값은 전송하지 않아요.
`open` · `defaultOpen` · `onOpenChange`로 달력의 열림을 제어할 수 있어요(`input`).

## 접근성

- 필드는 버튼이고 이름은 "현재 값 + 라벨"이에요. 메시지는 설명으로 연결되고, 오류는 `aria-invalid`로 전달돼요.
- 열린 달력은 대화상자(`dialog`)로, 포커스가 안으로 들어갔다가 닫히면 필드로 돌아와요.
- 달력의 날짜 버튼은 "20 2026년 7월 20일 월요일"처럼 숫자를 먼저 읽어요. 고를 수 없는 날은 비활성으로 알려요.

## Calendar와의 관계

`Calendar`는 그대로 제공돼요(호환). 새 화면에서는 `DatePicker variant="inline"`을 써 주세요. 두 컴포넌트는 같은 달력을 그려요.
