# DatePicker

DatePicker는 날짜를 직접 입력하거나 달력에서 고르는 입력 칸입니다. 달력만 화면에 펼쳐 두려면 `Calendar`를 씁니다.

<Canvas of={Showcase.Overview} />

## 언제 사용하나요

| 컴포넌트 | 쓰임 |
| --- | --- |
| `DatePicker` | 시작일 · 방문일처럼 폼에서 날짜 하나를 입력받을 때 |
| `Calendar` | 일정 화면처럼 달력을 펼쳐 두고 날짜를 고를 때 |

## 종류

- 크기는 `size`(`sm` · `md` · `lg`)로 고릅니다. 기본은 `sm`입니다.
- 입력 칸 위에는 `label`, 아래에는 도움말 메시지 `message`를 둘 수 있습니다.
- 메시지 종류는 `messageType`(`helper` · `info` · `success` · `error`)으로 고릅니다. 지정하지 않으면 오류일 때 `error`, 그 밖에는 회색 도움말(`helper`)입니다.

## 필수 입력

<Canvas of={Showcase.RequiredMark} />

- `required`를 주면 라벨 뒤에 점이 붙어 꼭 입력해야 하는 칸임을 알립니다. 점은 라벨이 있을 때만 보입니다.
- 점은 표의 필수 항목(`KeyValueItem required`)과 같은 색 · 크기입니다.

## 도움말

<Canvas of={Showcase.HelperMessage} />

- 입력 방법이나 형식은 입력 칸 아래 회색 도움말로 미리 알려 줍니다. `message`만 넣으면 도움말로 보입니다.
- 도움말에는 아이콘이 없습니다. 상태를 알릴 때만 안내(`info`) · 성공(`success`) · 오류(`error`)를 씁니다.
- 오류가 나면 같은 자리에 오류 메시지를 보여 줍니다. 비활성 칸의 도움말은 흐린 색입니다.
- 도움말은 입력 칸 설명으로 화면 낭독기가 함께 읽습니다.

## 상태

<Canvas of={Showcase.States} />

- 마우스를 올리거나 키보드로 선택하면 입력 칸 테두리가 바뀝니다.
- 날짜가 들어 있으면 입력을 마친 모양으로 바뀝니다.
- `invalid`이면 오류 상태입니다. 없는 날짜나 고를 수 없는 날짜를 입력해도 오류 상태가 됩니다.
- `disabled`이면 입력할 수 없습니다.
- `readOnly`이면 읽기 전용입니다. 날짜만 보여 주고 달력 버튼이 없습니다.

## 사용 방법

<Source
  language="tsx"
  code={`import { DatePicker, Calendar } from 'platform-design-system';

// 값은 'YYYY-MM-DD' 문자열이고, 화면에는 YYYY.MM.DD로 보입니다
<DatePicker label="시작일" name="start" value={start} onChange={setStart} />

// 필수 입력 — 라벨 뒤에 점
<DatePicker label="방문일" name="visit" required />

// 고를 수 있는 기간을 정하고 주말은 막습니다
<DatePicker label="상담일" minValue="2026-07-06" maxValue="2026-08-31"
  isDateUnavailable={(iso) => [0, 6].includes(new Date(iso + 'T00:00').getDay())} />

// 달력만 쓸 때
<Calendar aria-label="일정" value={day} onChange={setDay} />

// 언어 — 월 · 요일 이름은 I18nProvider의 언어를 따릅니다(없으면 브라우저 언어)
<I18nProvider locale="ko-KR"><App /></I18nProvider>`}
/>

- 날짜를 직접 입력할 수 있습니다. YYYY.MM.DD · YYYY-MM-DD · YYYY/MM/DD · YYYYMMDD 형식을 받습니다.
- 입력한 날짜는 Enter를 누르거나 입력 칸을 벗어나면 확정됩니다.
- 고를 수 있는 날짜는 `minValue` · `maxValue` · `isDateUnavailable`로 정합니다.
- `name`을 주면 폼을 보낼 때 `YYYY-MM-DD` 값이 함께 전송됩니다.
- 달력은 입력 칸 아래에 열리고, 아래 공간이 없으면 위로 열립니다.

## 달력

<Canvas of={CalendarShowcase.Overview} />

- 오늘, 선택된 날짜, 다른 달의 날짜, 고를 수 없는 날짜는 모양이 서로 다릅니다.
- 고를 수 있는 기간의 첫 달에서는 이전 달 버튼이, 마지막 달에서는 다음 달 버튼이 비활성입니다.
- 월 · 요일 이름은 언어 설정을 따릅니다. 한국어라면 요일이 "일 월 화 …"로 보입니다.

## 접근성

- `label`이 없으면 `aria-label`로 이름을 꼭 붙입니다.
- `required`이면 날짜 입력 칸이 "필수"로 읽힙니다(점은 장식이라 읽지 않습니다).
- 달력 버튼은 화면 낭독기가 "달력 열기"로 읽습니다. 다른 말이 필요하면 `calendarButtonLabel`로 바꿉니다.
- 화면 낭독기는 날짜 칸을 보이는 숫자와 전체 날짜(요일 포함)로 읽습니다.

| 위치 | 키 | 동작 |
| --- | --- | --- |
| 입력 칸 | 날짜 입력 후 Enter · Tab | 날짜 확정 |
| 입력 칸 | Alt + ↓ | 달력 열기 |
| 달력 | ← → ↑ ↓ | 하루 · 한 주 이동 |
| 달력 | Page Up · Page Down | 이전 · 다음 달 |
| 달력 | Enter · Space | 날짜를 고르고 닫기 |
| 달력 | Esc | 닫기 |

## 주의사항

- 값은 `YYYY-MM-DD` 형식의 문자열이고, 비어 있으면 `null`입니다.
- 잘못 입력한 날짜는 값을 바꾸지 않고 오류 상태로만 보여 줍니다. 이때 `onChange`는 호출되지 않습니다.
