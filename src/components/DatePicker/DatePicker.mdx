# DatePicker

입력창 없이 달력에서 날짜 또는 기간을 선택해요. 라벨과 안내가 필요 없으면 같은 달력 엔진을 사용하는 Calendar를 사용할 수 있어요.

<Canvas of={Showcase.Overview} />

## Single / Range

- Single은 날짜 하나를 선택해요.
- Range는 시작일을 누른 뒤 종료일을 눌러요. 앞선 날짜를 두 번째로 선택하면 날짜 순서대로 정렬해요.
- 같은 날짜를 두 번 선택하면 하루짜리 기간이 돼요. 완성된 기간에서 다시 날짜를 누르면 새 선택을 시작해요.
- 시작일 선택 후 마우스를 올리거나 키보드로 이동하면 임시 범위가 보여요. 두 번째 선택 전에는 값이 확정되지 않아요.
- 비활성 날짜를 포함하는 연속 기간은 선택할 수 없어요. 이전·다음 달로 이동해 여러 달에 걸친 기간을 선택할 수 있어요.

## Year / Month

연도와 월을 각각 선택해 이동해요. 연도를 바꾸면 현재 월을 유지하고, 그 월이 제한 범위를 벗어나면 선택 가능한 가장 가까운 월로 이동해요.

연도 목록은 표시 연도 전후 10년을 제공해요. 다른 연도를 선택하면 목록도 그 연도를 중심으로 이동해요. minValue / maxValue 밖의 연도·월과 선택할 수 있는 날짜가 없는 연도·월은 목록에서 제외해요. 월 이동 버튼으로도 계속 탐색할 수 있어요.

## Usage

<Source code={`<DatePicker label="방문일" value={date} onChange={setDate} />

<DatePicker
  label="이용 기간"
  selectionMode="range"
  rangeValue={range}
  onRangeChange={setRange}
  minValue="2026-01-01"
  maxValue="2026-12-31"
/>`} />

단일 날짜는 ISO 문자열 또는 null을 사용해요. 기간은 `{ start: 'YYYY-MM-DD', end: 'YYYY-MM-DD' }` 또는 null이에요.
`defaultValue` / `defaultRangeValue`는 비제어 방식의 초깃값이에요. `defaultFocusedValue`로 처음 표시할 달을 지정할 수 있어요.

`disabled`는 전체 조작을 막고, `readOnly`는 날짜 변경만 막아요. `required`는 필수 표시와 접근성 정보를 제공하며, 입력창이 없으므로 제출 시 누락 검증은 폼에서 처리해 주세요.
`name`이 있으면 Single은 해당 이름으로, Range는 `name.start`와 `name.end`로 확정된 날짜를 전송해요. 비활성 값은 전송하지 않아요.

## Breaking change · Calendar형 전환

- 날짜 입력창과 달력 팝오버를 제거했어요. 달력은 항상 표시돼요.
- `size`, `placeholder`, `open`, `onOpenChange`, `calendarButtonLabel`을 제거했어요.
- `id`는 입력창 대신 달력 루트에 적용돼요. 텍스트 입력·blur·Alt+↓ 동작은 더 이상 제공하지 않아요.
- Single의 `value/defaultValue/onChange`는 유지해요. Range는 별도의 `rangeValue/defaultRangeValue/onRangeChange`를 사용해요.
- 좁은 한 줄 입력칸에 그대로 넣지 말고 달력 폭 296px을 확보해 주세요. 기간 입력창 두 개는 Range 달력 하나로 바꿔 주세요.
- Calendar도 같은 TextButton형 연도·월 헤더를 사용해요. 기존 Single API는 유지해요.
