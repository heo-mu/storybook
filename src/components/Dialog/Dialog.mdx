# Dialog

사용자의 확인이나 선택이 필요할 때 여는 모달 대화상자입니다. 열린 동안 배경 화면의 조작을 제한합니다.

<Canvas of={DialogStories.Confirm} />

## 사용 시점

- 다음으로 넘어가기 전에 사용자의 확인이나 선택이 필요할 때 씁니다.
- 삭제처럼 사용자의 흐름을 멈추고 확인받아야 할 때는 `role="alertdialog"`를 씁니다.

## 사용 예시

<Source
  language="tsx"
  code={`import { Button, Dialog } from 'platform-design-system';

<Dialog
  trigger={<Button>삭제</Button>}
  role="alertdialog"
  title="파일을 삭제할까요?"
  description="삭제한 파일은 되돌릴 수 없습니다."
  actions={(close) => (
    <>
      <Button variant="tertiary" appearance="solid" size="lg" onClick={close}>취소</Button>
      <Button size="lg" onClick={() => { remove(); close(); }}>삭제</Button>
    </>
  )}
/>

// 직접 열고 닫기
<Dialog open={open} onOpenChange={setOpen} title="…" actions={…} />`}
/>

- `trigger`로 넘긴 요소를 누르면 열립니다. 직접 열고 닫으려면 `open`과 `onOpenChange`를 씁니다.
- 버튼은 `actions`에 넣으며, 같은 너비로 나란히 놓입니다. 함수로 넘기면 대화상자를 닫는 `close`를 받습니다.
- 버튼은 취소에 `Button`의 `tertiary` · `solid` · `lg`, 주 행동에 `primary` · `solid` · `lg`를 씁니다.
- 제목과 버튼 사이에 내용이 필요하면 `children`으로 넣습니다.

## 접근성

- 열리면 포커스가 대화상자 안으로 옮겨지고, Tab · Shift+Tab은 대화상자 안에서만 움직입니다.
- 닫히면 대화상자를 연 요소로 포커스가 돌아갑니다.
- `title`은 대화상자의 이름, `description`은 설명으로 화면 낭독기가 읽습니다.

## 사용 규칙

- Esc를 누르면 닫힙니다. 막으려면 `keyboardDismissDisabled`를 씁니다.
- 바깥을 눌러 닫는 것은 `dismissable`일 때만 됩니다. 입력한 내용을 잃지 않도록 기본으로 꺼져 있습니다.
- 닫기(X) 버튼은 없습니다. 닫는 버튼은 `actions`에 넣습니다.
- 크기는 한 가지(420px)입니다. 확인 · 선택처럼 짧은 내용에 쓰고, 안에 넣는 입력 필드는 1–2개까지로 합니다. 입력할 항목이 많으면 대화상자 대신 화면으로 만듭니다.
