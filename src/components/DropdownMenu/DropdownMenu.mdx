# DropdownMenu

DropdownMenu는 버튼을 누르면 펼쳐지는 동작 메뉴입니다. 새 폴더 · 이동 · 삭제처럼 고를 수 있는 작업을 모아 보여 줍니다.

<Canvas of={Showcase.Overview} />

## 언제 사용하나요

| 컴포넌트 | 쓰임 |
| --- | --- |
| `DropdownMenu` | 메뉴를 여는 버튼(`trigger`)과 메뉴 |
| `DropdownMenuItem` | 메뉴 항목 하나 |
| `DropdownMenuSection` | 제목을 붙인 항목 묶음 |
| `DropdownMenuSeparator` | 묶음 사이의 구분선 |

## 종류

- `icon`으로 항목 앞에 아이콘을 붙입니다.
- `description`으로 항목 이름 아래에 설명을 붙입니다.
- `chevron`을 켜면 오른쪽 화살표가 붙습니다. 다른 화면으로 이동하는 항목이라는 표시이며, 하위 메뉴는 지원하지 않습니다.
- `danger`는 삭제처럼 위험한 작업에 씁니다.

## 상태

- 마우스를 올리거나 키보드로 선택하면 항목의 모양이 바뀝니다. 두 경우의 모양은 같습니다.
- `disabled`이면 고를 수 없고, 방향키로 옮길 때도 건너뜁니다.
- 메뉴가 열려도 트리거 버튼의 모양은 바뀌지 않습니다.

## 사용 방법

<Source
  language="tsx"
  code={`import { Button, DropdownMenu, DropdownMenuItem, DropdownMenuSection, DropdownMenuSeparator } from 'platform-design-system';

<DropdownMenu trigger={<Button>작업</Button>} aria-label="작업" onAction={(key) => run(key)}>
  <DropdownMenuSection title="파일">
    <DropdownMenuItem id="new" icon={<FolderIcon />}>새 폴더</DropdownMenuItem>
    <DropdownMenuItem id="move" icon={<FolderIcon />} chevron description="다른 위치로">이동</DropdownMenuItem>
    <DropdownMenuItem id="lock" disabled>잠금</DropdownMenuItem>
  </DropdownMenuSection>
  <DropdownMenuSeparator />
  <DropdownMenuItem id="delete" danger>삭제</DropdownMenuItem>
</DropdownMenu>`}
/>

- 항목을 고르면 `onAction`이 그 항목의 `id`로 호출되고 메뉴가 닫힙니다.
- `trigger`에는 `Button`이나 `FilterChip`처럼 누를 수 있는 요소를 넘깁니다.
- 메뉴는 트리거 아래에 열리고, 화면 밖으로 나가면 반대쪽으로 열립니다. 위치는 `placement`, 트리거와의 간격은 `offset`으로 바꿉니다.
- 메뉴 너비는 내용에 맞춰집니다. 너비를 정하려면 `className`을 씁니다.

## 접근성

- `aria-label`로 메뉴 이름을 붙입니다.
- 제목이 없는 `DropdownMenuSection`에는 `aria-label`로 이름을 붙입니다.
- 화면 낭독기는 항목 이름과 설명을 함께 읽습니다.
- 트리거는 메뉴가 열렸는지를 화면 낭독기에 알립니다.

| 키 | 동작 |
| --- | --- |
| Enter · Space · ↓ (트리거) | 메뉴를 열고 첫 항목으로 이동(↑는 마지막 항목) |
| ↑ · ↓ · Home · End | 항목 이동(비활성 항목은 건너뜀) |
| 글자 입력 | 그 글자로 시작하는 항목으로 이동 |
| Enter · Space | 항목을 실행하고 닫기 |
| Esc | 닫고 트리거로 돌아가기 |
| 바깥 누르기 | 닫기 |
