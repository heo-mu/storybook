## Figma 속성 → Props

| Figma | Prop | 비고 |
| --- | --- | --- |
| Title Text | `title` | |
| Description · Description Text | `description` | 가운데 정렬, 줄바꿈 |
| Icon | `icon` | 16px, 장식 |
| 버튼(button_text) | `action` | Figma: TextButton Primary sm + CaretRight |

## 코드 정책 (Figma에 정의되지 않은 부분)

- **버튼 유무**: Figma에는 버튼을 끄는 속성이 없지만 버튼이 필요 없는 빈 상태가 있어 `action`을 선택으로 두었습니다.
- **너비**: Figma처럼 320px, 부모가 더 좁으면 그 너비로 줄어듭니다.
