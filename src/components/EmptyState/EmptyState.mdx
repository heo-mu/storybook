# EmptyState

목록이나 차트에 표시할 내용이 없을 때 이유와 다음 행동을 안내합니다.

<Canvas of={Showcase.Overview} />

## 사용 시점

- 아직 데이터가 없거나 검색 결과가 없을 때 씁니다.

## 사용 예시

<Source
  language="tsx"
  code={`import { EmptyState, TextButton, CaretRightIcon, DatabaseIcon } from 'platform-design-system';

<EmptyState
  icon={<DatabaseIcon />}
  title="아직 수집된 데이터가 없습니다"
  description="수집 설정과 데이터 연결을 확인하세요."
  action={<TextButton rightIcon={<CaretRightIcon />} onClick={openSettings}>수집 설정 확인</TextButton>}
/>`}
/>

- 제목(`title`)은 꼭 넣고, 아이콘(`icon`) · 설명(`description`) · 버튼(`action`)은 필요할 때만 넣습니다.
- 사용자가 할 일이 없는 빈 상태에는 버튼을 두지 않습니다.
- 버튼은 `TextButton`에 오른쪽 화살표 아이콘(`CaretRightIcon`)을 붙여 씁니다.
- 너비는 320px이고, 부모가 더 좁으면 그 너비에 맞춰 줄어듭니다.

## 접근성

- 아이콘은 꾸밈으로 처리되어 화면 낭독기가 읽지 않습니다.
