# FileUploader

드래그 앤 드롭 또는 파일 선택 창으로 파일을 받습니다. 선택한 파일은 FileUploaderItem으로 표시합니다.

<Canvas of={Showcase.Overview} />

## 사용 시점

| 컴포넌트 | 쓰임 |
| --- | --- |
| `FileUploader` | 파일을 끌어다 놓거나 파일 선택 창에서 고르는 영역 |
| `FileUploaderItem` | 고른 파일 하나를 목록에 보여 주는 줄. 삭제 · 다운로드 버튼이나 업로드 중 표시가 붙습니다 |
| `Loading` | 불러오거나 처리하는 중임을 알리는 회전 표시 |

## 종류

- `FileUploader`는 제목 `title`과 안내 문구 `helperText`(허용 형식 · 크기 제한 등)를 보여 줍니다.
- 제목을 지정하지 않으면 "파일을 끌어다 놓거나 선택하세요"가 보입니다. 업로드 아이콘은 `showIcon`으로 숨길 수 있습니다.
- `Loading`은 `size`(`md` · `sm`)로 크기를 고르고, `label`로 아래에 글자를 붙입니다.

`FileUploaderItem`은 `status`에 따라 오른쪽 끝이 바뀝니다.

| `status` | 모양 |
| --- | --- |
| `completed` (기본) | "삭제" 버튼 — 누르면 `onRemove` |
| `uploading` | 회전하는 로딩 표시 |
| `download` | "다운로드" 버튼 — 누르면 `onDownload` |
| `error` | 업로드 실패 — 파일 정보(`fileInfo`)가 오류 색으로 바뀌고 "삭제" 버튼은 그대로 — 누르면 `onRemove` |

## 상태

<Canvas of={Showcase.States} />

- 마우스를 올리거나 누르면 업로드 영역의 모양이 바뀝니다.
- 파일을 영역 위로 끌어오면 놓을 수 있다는 모양으로 바뀝니다.
- `disabled`이면 Figma Disabled 상태로 보입니다 — 배경 `surface/container`, 점선 테두리 `border/disabled`, 제목 `text/inactive`(안내 문구는 `text/tertiary`, 아이콘 색은 그대로, 흐림 효과 없음).
  누를 수 없고 Tab 순서에서 빠지며, 파일을 끌어다 놓으면 "놓을 수 없음" 커서가 보이고 받지 않습니다(브라우저가 파일을 여는 기본 동작도 막습니다).
- 키보드 포커스를 받으면 포커스 테두리가 보입니다.
- 긴 파일 이름은 말줄임표(…)로 줄여 보여 줍니다.

## 사용 예시

<Source
  language="tsx"
  code={`import { FileUploader, FileUploaderItem } from 'platform-design-system';

const [files, setFiles] = useState<Upload[]>([]);

<FileUploader
  helperText="PDF, HWP, DOCX, JPG, PNG · 파일당 10 MB · 최대 5개"
  accept=".pdf,.hwp,.docx,.jpg,.png"
  multiple
  onFilesSelected={(picked) => startUpload(picked)}
/>

{files.map((f) => (
  <FileUploaderItem
    key={f.id}
    fileName={f.name}
    fileInfo={f.failed ? \`\${f.size} · 업로드 실패\` : f.done ? \`\${f.size} · 업로드 완료\` : \`\${f.size} · 업로드 중\`}
    status={f.failed ? 'error' : f.done ? 'completed' : 'uploading'}
    onRemove={() => remove(f.id)}
  />
))}`}
/>

- 선택 창에서 고른 파일과 끌어다 놓은 파일 모두 `accept`에 맞는 것만 `onFilesSelected`로 전달됩니다.
- `multiple`이 아니면 첫 파일 하나만 전달됩니다.
- 파일 크기 · 개수 검사와 실제 업로드는 사용하는 화면에서 처리합니다.
- 업로드에 실패한 파일은 목록에 남겨 `status="error"`로 보여 주고, `fileInfo`에 실패 이유를 적습니다(예: "24 MB · 파일당 10 MB를 넘어 업로드 실패").

## 접근성

- 업로드 영역은 버튼입니다. Enter · Space로도 파일 선택 창을 엽니다. `disabled`이면 버튼과 숨은 파일 입력이 모두 비활성이라 선택 창이 열리지 않습니다.
- 화면 낭독기는 `helperText`를 업로드 영역의 설명으로 함께 읽습니다.
- "삭제" · "다운로드" 버튼은 파일 이름을 설명으로 함께 읽어, 어느 파일의 버튼인지 구분됩니다. 업로드에 실패한 파일(`error`)의 "삭제" 버튼은 실패 이유도 함께 읽습니다.
- `Loading`은 화면 낭독기가 `label`을 읽습니다. `label`이 없으면 `aria-label`로 이름을 붙이고, 그것도 없으면 "로딩 중"으로 읽습니다.
- 기기에서 움직임 줄이기를 켜면 로딩 표시가 더 천천히 돕니다.
