# Link

Link는 다른 페이지나 문서로 이동하는 밑줄 글자 링크입니다.

<Canvas of={Showcase.Overview} />

## 언제 사용하나요

- 이용약관처럼 다른 페이지나 문서로 이동할 때 씁니다.
- 새 창으로 여는 링크에는 `external`을 켭니다.

## 종류

- 크기는 `size`(`sm` · `md` · `lg`)로 고릅니다. 기본은 `sm`입니다.
- `external`을 켜면 새 창으로 열리고, 글자 뒤에 새 창 아이콘이 붙습니다.
- 새 창 아이콘은 새 창으로 여는 링크에만 씁니다. 아이콘을 따로 켜고 끄려면 `showIcon`을 씁니다.

## 상태

<Canvas of={Showcase.States} />

- 마우스를 올리거나 누르면 모양이 바뀝니다.
- 이미 방문한 링크는 방문한 모양으로 보입니다.
- `disabled`이면 누를 수 없고 키보드로도 선택되지 않습니다.
- 키보드로 선택하면 포커스 테두리가 보입니다.

## 사용 방법

<Source
  language="tsx"
  code={`import { Link } from 'platform-design-system';

<Link href="/terms">이용약관</Link>

// 새 창으로 열기 (아이콘이 붙고, 화면 낭독기는 "(새 창)"을 함께 읽습니다)
<Link href="https://www.figma.com" external>Figma 열기</Link>

// 라우터 링크처럼 다른 컴포넌트로 그려야 하면 클래스만 가져다 씁니다
<a className="ds-link" data-size="sm" href="/docs">문서</a>`}
/>

## 접근성

- `external` 링크는 화면 낭독기가 글자 뒤에 "(새 창)"을 함께 읽습니다. 다른 말이 필요하면 `newTabLabel`로 바꿉니다.
- `disabled` 링크는 화면 낭독기에 비활성 링크로 알려집니다.
