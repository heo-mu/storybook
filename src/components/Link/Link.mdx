# Link — 사용 가이드

Figma **Link** 프레임(111:960)의 `link` 세트(15개)를 구현한 밑줄 텍스트 링크입니다. 네이티브 `<a>`를 사용합니다.

<Canvas of={Showcase.Overview} />

## 사용 예

<Source
  language="tsx"
  code={`import { Link } from 'platform-design-system';

<Link href="/terms">이용약관</Link>

// 새 창 (아이콘 + 스크린리더 "(새 창)")
<Link href="https://www.figma.com" external>Figma 열기</Link>

// 라우터 링크 — 다른 컴포넌트로 렌더링이 필요하면 클래스만 재사용
<a className="ds-link" data-size="sm" href="/docs">문서</a>`}
/>

## Figma 속성 → Props

| Figma | Prop | 비고 |
| --- | --- | --- |
| Size sm · md · lg | `size` | 글자 12 · 14 · 16px, 밑줄 |
| Label Text | children | |
| Icon (arrow-square-out) | `showIcon` | 기본값은 `external` |
| State Hover · Pressed · Visited | 브라우저 `:hover` · `:active` · `:visited` | |
| State Disabled | `disabled` | href 제거, `aria-disabled`, Tab 순서에서 빠짐 |

## 코드 정책 (Figma에 정의되지 않은 동작)

- **외부 링크**: Figma의 화살표 아이콘을 "새 창으로 열림" 표시로 해석해 `external`과 연결했습니다
  (`target="_blank"`, `rel="noopener noreferrer"`, 숨은 "(새 창)" 텍스트). 아이콘만 필요하면 `showIcon`.
- **포커스 표시**: Figma에 Focus 상태가 없어 브라우저 기본 포커스 링을 사용합니다.
- **md 줄 높이**: md 텍스트 스타일 `sm/leading-normal/underline`은 140%(19.6px)이고 삭제된 변수에 연결되어 있습니다(figma-issues C3).
  Figma처럼 20px 줄로 배치합니다.
