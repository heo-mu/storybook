# MetricCard

핵심 지표의 값과 단위, 이전 기간 대비 변화를 요약합니다.

<Canvas of={Showcase.Figma} />

## 사용 시점

- 대시보드에서 핵심 지표 하나를 크게 보여 줄 때 씁니다.
- 지표가 여러 개면 카드를 가로로 나란히 둡니다.

<Canvas of={MetricCardStories.Row} />

## 구성

| Prop | 내용 |
| --- | --- |
| `title` | 지표 이름. 카드 제목으로 표시됩니다. |
| `icon` | 제목 앞 아이콘 |
| `value` · `unit` | 값과 단위 |
| `trend` | 증감. 보통 `MetricTrend`를 넣습니다. |
| `comparison` | 비교 기준 문구(예: "이전 7일 대비") |

- `title`과 `value`만 꼭 넣고, 나머지는 필요할 때만 넣습니다.

## 사용 예시

<Source
  language="tsx"
  code={`import { LightningIcon, MetricCard, MetricTrend } from 'platform-design-system';

<MetricCard
  title="누적 전력 사용량"
  icon={<LightningIcon />}
  value="1,248"
  unit="kWh"
  trend={<MetricTrend direction="down" tone="positive">4.8%p</MetricTrend>}
  comparison="이전 7일 대비"
/>`}
/>

## 접근성

- 카드 전체가 제목을 이름으로 하는 하나의 묶음으로 읽힙니다.
- 제목은 제목 요소(기본 `<h3>`)입니다. 페이지 구조에 맞게 `headingLevel`로 바꿉니다.
- 아이콘은 꾸밈으로 처리되어 화면 낭독기가 읽지 않습니다.

## 사용 규칙

- 카드는 부모 너비를 채웁니다. 너비는 카드를 감싼 영역에서 정합니다.
