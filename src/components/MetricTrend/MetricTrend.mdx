# MetricTrend

지표가 얼마나 늘거나 줄었는지를 방향 아이콘과 함께 보여 줍니다.

<Canvas of={Showcase.Figma} />

## 언제 사용하나요

- 지표 값 옆에 이전 기간과 비교한 증감을 보여 줄 때 씁니다. 보통 `MetricCard`의 `trend`에 넣습니다.

## 종류

| `direction` | 뜻 |
| --- | --- |
| `up` | 증가 |
| `down` | 감소 |
| `flat` | 변동 없음 |
| `disabled` | 비교할 값이 없음. `tone`과 관계없이 회색으로 표시합니다. |

| `tone` | 뜻 | 색 |
| --- | --- | --- |
| `positive` | 좋은 변화 | 브랜드 색 |
| `negative` | 나쁜 변화 | 빨간색 |
| `neutral` | 좋지도 나쁘지도 않음 | 회색 |

- 방향과 좋고 나쁨은 따로 정합니다. 사용량처럼 줄어드는 것이 좋은 지표는 `direction="down"` `tone="positive"`를 씁니다.

## 사용 방법

<Source
  language="tsx"
  code={`import { MetricTrend } from 'platform-design-system';

// 사용량이 줄어든 것이 좋은 지표
<MetricTrend direction="down" tone="positive">4.8%p</MetricTrend>`}
/>

## 접근성

- 방향은 아이콘으로만 보이므로, 화면 낭독기는 값 앞에 "증가" · "감소" · "변동 없음"을 읽습니다. `directionLabel`로 바꿀 수 있고, `disabled`는 읽지 않습니다.
- 좋고 나쁨(`tone`)은 색으로만 구분됩니다. 의미가 중요하면 주변 문장(예: `MetricCard`의 비교 문구)에서 설명합니다.
