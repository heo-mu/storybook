# Navigation

Navigation은 화면 왼쪽에 두는 메뉴(LNB)입니다. 바로 이동하는 메뉴와, 펼쳐서 하위 메뉴를 보여 주는 메뉴 그룹으로 이루어집니다.

<Canvas of={Showcase.Overview} />

## 언제 사용하나요

| 컴포넌트 | 쓰임 |
| --- | --- |
| `Navigation` | 메뉴 전체를 감싸는 틀. 메뉴 위에 로고 등을 `header`로 둘 수 있습니다 |
| `NavLink` | 누르면 바로 페이지로 이동하는 첫 단계 메뉴 |
| `NavGroup` | 눌러서 펼치고 접는 메뉴 그룹 |
| `NavChild` | `NavGroup` 안의 하위 메뉴 |

## 상태

- 마우스를 올리면 모양이 바뀝니다. 누를 때의 모양은 마우스를 올렸을 때와 같습니다.
- `NavLink` · `NavChild`에 `selected`를 주면 지금 페이지로 강조됩니다.
- `NavGroup`을 펼치면 화살표가 위쪽으로 바뀌고 하위 메뉴가 보입니다.
- 키보드로 선택하면 항목 안쪽에 포커스 테두리가 보입니다.
- 긴 메뉴 이름은 줄을 바꿔 보여 줍니다.

## 사용 방법

<Source
  language="tsx"
  code={`import { Navigation, NavGroup, NavChild, NavLink } from 'platform-design-system';

<Navigation aria-label="주 메뉴" header={<Logo />} style={{ width: 240 }}>
  <NavGroup label="에너지 관리" icon={<ChartIcon />} defaultExpanded>
    <NavChild href="/energy/usage">사용량</NavChild>
    <NavChild href="/energy/saving" selected>에너지 절약</NavChild>
  </NavGroup>
  <NavLink href="/dashboard" icon={<HomeIcon />}>대시보드</NavLink>
</Navigation>`}
/>

- 메뉴 항목은 `Navigation`의 너비를 꽉 채웁니다. 너비는 화면 배치에서 정합니다(예시는 240px).
- 메뉴 앞 아이콘은 `icon`으로 넘깁니다.
- 그룹을 처음부터 펼쳐 두려면 `defaultExpanded`를 씁니다. 펼침을 바깥에서 관리하려면 `expanded`와 `onExpandedChange`를 씁니다.

## 접근성

- `Navigation`에 `aria-label`로 메뉴 이름(예: "주 메뉴")을 붙이면 화면 낭독기가 메뉴를 구분할 수 있습니다.
- `selected` 항목은 화면 낭독기에 현재 페이지로 알려집니다.
- 메뉴 그룹은 버튼이며, 펼침 여부가 화면 낭독기에 알려집니다.

| 키 | 동작 |
| --- | --- |
| Tab · Shift+Tab | 메뉴 항목 사이 이동(접힌 그룹의 하위 메뉴는 건너뜀) |
| Enter · Space (그룹) | 펼치기 · 접기 |
| Enter (링크) | 페이지 이동 |
