# Pagination

여러 페이지로 나뉜 목록에서 현재 페이지를 표시하고 다른 페이지로 이동합니다.

<Canvas of={Showcase.Overview} />

## 사용 시점

- 표나 목록의 내용이 여러 페이지로 나뉠 때 씁니다.

## 종류

- 크기는 `size`(`sm` · `md` · `lg`), 모서리는 `shape`(`square` · `rounded`)로 고릅니다. 기본은 `sm` · `square`입니다.
- 한 번에 보이는 페이지 번호 수는 `visiblePages`로 정합니다. 기본은 5개입니다.

## 상태

<Canvas of={Showcase.States} />

- 마우스를 올리거나 누르면 모양이 바뀝니다.
- 현재 페이지 번호는 선택 상태로 표시합니다.
- 첫 페이지에서는 이전 버튼이, 마지막 페이지에서는 다음 버튼이 비활성입니다.
- 키보드 포커스를 받으면 포커스 테두리가 보입니다.

## 사용 예시

<Source
  language="tsx"
  code={`import { Pagination } from 'platform-design-system';

<Pagination totalPages={pageCount} page={page} onPageChange={setPage} />

// 크기 · 모양
<Pagination totalPages={20} size="md" shape="rounded" visiblePages={7} />`}
/>

- 페이지 번호는 1부터 셉니다.
- 페이지가 많으면 현재 페이지를 가운데 두고 `visiblePages`개 번호만 보여 줍니다.
- 생략 표시(…)와 처음 · 끝으로 가는 버튼은 없습니다.
- 현재 페이지를 바깥에서 관리하려면 `page`와 `onPageChange`를 함께 씁니다. 지정하지 않으면 `defaultPage`를 초깃값으로 사용해 내부에서 관리합니다.

## 접근성

- 화면 낭독기는 전체를 "페이지 이동" 영역으로 읽습니다. 다른 이름이 필요하면 `aria-label`로 바꿉니다.
- 번호 버튼은 "3 페이지"처럼, 이동 버튼은 "이전 페이지" · "다음 페이지"로 읽습니다.
- 현재 페이지 번호는 화면 낭독기에 현재 페이지로 알려집니다.
