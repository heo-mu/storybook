# Progress

진행 막대는 작업이 얼마나 진행되었는지 막대 길이로 보여 줍니다.

<Canvas of={Showcase.Overview} />

## 언제 사용하나요

- 업로드처럼 진행률을 알 수 있는 작업에 씁니다.
- 진행률을 알 수 없으면 진행 막대 대신 Loading을 씁니다.

## 사용 방법

<Source
  language="tsx"
  code={`import { Progress } from 'platform-design-system';

<Progress aria-label="업로드" value={percent} />
<Progress aria-labelledby="job-title" value={done} maxValue={total} valueLabel={\`\${total}개 중 \${done}개\`} />`}
/>

- `value`는 `minValue`와 `maxValue` 사이의 값입니다. 기본 범위는 0 – 100입니다.
- 막대는 부모 너비를 채웁니다.

## 접근성

- `aria-label` 또는 `aria-labelledby`로 이름을 꼭 붙입니다.
- 막대에는 라벨이나 수치가 보이지 않습니다. 화면 낭독기가 읽을 수치 설명은 `valueLabel`로 전합니다.
