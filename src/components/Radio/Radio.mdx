# Radio

여러 옵션 중 하나만 고르는 라디오 버튼입니다. 보통 `RadioGroup`으로 묶어 사용합니다.

<Canvas of={Showcase.Overview} />

## 언제 사용하나요

| 컴포넌트 | 쓰임 |
| --- | --- |
| `Radio` | 고를 수 있는 옵션 하나 |
| `RadioGroup` | 라디오 버튼들을 묶어 선택한 값 하나를 관리할 때 |

## 종류

- 크기는 `size`(`sm` · `md` · `lg`)로 고릅니다. 기본은 `sm`이고, 그룹 안에서는 그룹의 `size`를 따릅니다.
- `RadioGroup`의 `orientation`으로 세로(`vertical`, 기본) 또는 가로(`horizontal`) 배치를 고릅니다. 항목 사이 간격은 자동으로 맞춰집니다.

## 상태

<Canvas of={Showcase.States} />

- 마우스를 올리거나 누르면 모양이 바뀝니다.
- `disabled`이면 누를 수 없습니다. 그룹 전체를 막으려면 `RadioGroup`에 `disabled`를 줍니다.
- 키보드로 선택하면 원 둘레에 포커스 테두리가 보입니다.

## 사용 방법

<Source
  language="tsx"
  code={`import { Radio, RadioGroup } from 'platform-design-system';

<RadioGroup aria-label="배송 방법" defaultValue="normal" name="delivery">
  <Radio value="normal" label="일반 배송" />
  <Radio value="express" label="빠른 배송" />
</RadioGroup>

// 제어 컴포넌트
<RadioGroup aria-label="기간" value={period} onChange={setPeriod} orientation="horizontal">
  <Radio value="7d" label="7일" />
  <Radio value="30d" label="30일" />
</RadioGroup>`}
/>

## 묶음 오류

<Canvas of={Showcase.GroupMessage} />

- 꼭 골라야 하는 항목을 고르지 않았으면 `invalid`와 `message`로 묶음 아래에 오류 메시지를 보여 줍니다. 라디오 버튼 색은 바뀌지 않습니다.
- `invalid` 없이 `message`만 넣으면 회색 도움말로 보입니다.
- 화면 낭독기는 묶음을 오류 상태로 알리고 메시지를 각 라디오 버튼의 설명으로 읽습니다.

<Source
  language="tsx"
  code={`<RadioGroup aria-label="구분" value={kind} onChange={setKind} required
  invalid={submitted && !kind} message={submitted && !kind ? '구분을 고르세요.' : undefined}>
  <Radio value="normal" label="일반" />
  <Radio value="urgent" label="긴급" />
</RadioGroup>`}
/>

## 접근성

- `RadioGroup`에는 `aria-label` 또는 `aria-labelledby`로 그룹 이름을 붙입니다.
- `label`이 없는 라디오 버튼에는 `aria-label`로 이름을 꼭 붙입니다.
- 같은 그룹 안에서는 방향키로 선택이 이동합니다.

## 주의사항

- `RadioGroup` 안에서는 그룹의 `value` · `defaultValue` · `onChange`로 선택을 관리합니다.
- 그룹 없이 단독으로 쓸 때는 `name`과 `checked` · `defaultChecked`를 직접 지정합니다.
- `RadioGroup`의 `name`을 생략하면 자동으로 만들어집니다.
