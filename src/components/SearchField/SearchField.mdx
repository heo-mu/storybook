# SearchField

검색어를 입력하고 Enter 키로 검색을 요청합니다. 일반 텍스트 입력에는 Input을 사용합니다.

<Canvas of={Showcase.Overview} />

## 사용 시점

- 목록이나 화면에서 원하는 항목을 찾을 때 사용합니다.
- 검색이 아닌 일반 글자를 입력받을 때는 `Input`을 사용합니다.

## 종류

- `appearance`로 테두리 모양(`outline`)과 채운 모양(`solid`)을 고릅니다. 기본은 `outline`입니다.
- 크기는 `size`(`sm` · `md` · `lg`)로 고릅니다. 기본은 `sm`입니다.

## 상태

<Canvas of={Showcase.States} />

- 마우스를 올리거나 키보드 포커스를 받으면 모양이 바뀝니다.
- `invalid`이면 오류 테두리로 표시합니다.
- `disabled`이면 입력할 수 없습니다.
- 키보드 포커스가 있거나 오류 상태이면 지우기 버튼(X)이 나타납니다. 누르면 값이 비워지고 `onClear`가 호출되며, 입력 필드는 계속 선택된 채로 남습니다.

## 사용 예시

<Source
  language="tsx"
  code={`import { SearchField } from 'platform-design-system';

<SearchField label="입주민 검색" placeholder="이름 또는 동·호수" onSearch={(q) => runSearch(q)} />

// 라벨 없는 검색창
<SearchField aria-label="전체 검색" appearance="solid" size="md" />`}
/>

## 접근성

- `label`이 없으면 `aria-label`로 이름을 꼭 붙입니다.
- 지우기 버튼은 마우스용이라 Tab 키로 이동하지 않습니다.

## 사용 규칙

- `onSearch`는 Enter 키를 누를 때만 호출됩니다. 입력할 때마다 값을 받으려면 `onChange`를 씁니다.
- 값이 있을 때 Esc 키를 누르면 검색어가 지워집니다(모든 브라우저에서 같게 동작). 비어 있으면 Esc는 바깥으로 전달됩니다.
- 나머지 `<input>` 속성과 `ref`는 실제 입력 필드에 전달되고, `className` · `style`은 바깥 요소에 적용됩니다.
