# SegmentedControl

관련 옵션을 나란히 표시하고 하나를 선택합니다. 일간·주간·월간처럼 소수의 옵션을 전환할 때 사용합니다.

<Canvas of={Showcase.Overview} />

## 사용 시점

| 컴포넌트 | 쓰임 |
| --- | --- |
| `SegmentedControl` | 일간 · 주간 · 월간처럼 몇 개 안 되는 옵션 중 하나를 고를 때 |
| `SegmentedControlItem` | `SegmentedControl` 안의 옵션 하나 |

## 종류

- 크기는 `size`(`md` · `sm` · `xs`)로 고릅니다. 기본은 `md`입니다.
- 너비를 정하지 않으면 가장 긴 옵션에 맞춰 모든 옵션이 같은 너비가 됩니다.
- `style` · `className`으로 너비를 정하면 옵션들이 그 너비를 똑같이 나눠 씁니다.
- 옵션 글자는 한 줄로 보입니다. 옵션 너비보다 길면 말줄임표로 줄입니다.

## 상태

<Canvas of={Showcase.States} />

- 마우스를 올리거나 누르면 모양이 바뀝니다. 선택된 옵션은 모양이 그대로 유지됩니다.
- 옵션 하나만 막으려면 `SegmentedControlItem`에, 전체를 막으려면 `SegmentedControl`에 `disabled`를 줍니다.
- 키보드 포커스를 받으면 선택된 옵션 둘레에 포커스 테두리가 보입니다.
- 다른 옵션을 고르면 선택 배경이 그 옵션으로 미끄러지듯 옮겨 갑니다. 기기에서 동작 줄이기를 켜면 바로 바뀝니다.

## 사용 예시

<Source
  language="tsx"
  code={`import { SegmentedControl, SegmentedControlItem } from 'platform-design-system';

<SegmentedControl aria-label="기간" value={period} onChange={setPeriod} size="sm">
  <SegmentedControlItem value="day">일간</SegmentedControlItem>
  <SegmentedControlItem value="week">주간</SegmentedControlItem>
  <SegmentedControlItem value="month" disabled>월간</SegmentedControlItem>
</SegmentedControl>

// 너비 지정 — 옵션이 너비를 똑같이 나눔
<SegmentedControl aria-label="보기" defaultValue="list" style={{ width: 316 }}>…</SegmentedControl>`}
/>

## 접근성

- `aria-label` 또는 `aria-labelledby`로 이름을 꼭 붙입니다.
- 방향키로 선택이 이동하고, 비활성 옵션은 건너뜁니다.
- 화면 낭독기는 각 옵션을 "전체 n개 중 n번째"로 읽습니다.

## 사용 규칙

- 값은 선택된 옵션의 `value`입니다. `value` · `onChange`로 직접 관리하거나, `defaultValue`로 초깃값만 정합니다.
- 폼을 보낼 때 선택값이 함께 전송됩니다. 이름은 `name`으로 정하고, 생략하면 자동으로 만들어집니다.
