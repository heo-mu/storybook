# Select

옵션 목록에서 항목 하나를 선택합니다. SelectOption으로 목록을 구성합니다.

<Canvas of={Showcase.Overview} />

## 사용 시점

| 컴포넌트 | 쓰임 |
| --- | --- |
| `Select` | 여러 옵션 중 하나를 고르는 선택 필드 |
| `SelectOption` | `Select` 목록 안의 옵션 하나 |

## 종류

- 크기는 `size`(`sm` · `md` · `lg`)로 고릅니다. 기본은 `sm`이고, 옵션 높이도 크기에 맞춰집니다.
- 아무것도 고르지 않았을 때는 `placeholder`가 보입니다. 기본 글자는 `내용 선택`입니다.
- 선택한 값이 길면 한 줄로 줄이고 말줄임표로 표시합니다.
- 선택된 옵션은 굵은 글자와 체크 아이콘으로 표시됩니다. 체크 아이콘을 빼려면 `SelectOption`에 `checkIcon={false}`를 줍니다.
- `message`를 넣으면 선택 필드 아래에 메시지가 보입니다. 메시지 종류는 `messageType`(`helper` · `info` · `success` · `error`)으로 고르고, 지정하지 않으면 오류일 때 `error`, 아니면 회색 도움말(`helper`)입니다.

## 필수 입력

<Canvas of={Showcase.RequiredMark} />

- `required`를 주면 라벨 뒤에 점이 붙어 꼭 골라야 하는 칸임을 알립니다. 점은 라벨이 있을 때만 보입니다.
- 점은 표의 필수 항목(`KeyValueItem required`)과 같은 색 · 크기입니다.

## 도움말

<Canvas of={Showcase.HelperMessage} />

- 입력 방법이나 형식은 선택 필드 아래 회색 도움말로 미리 알려 줍니다. `message`만 넣으면 도움말로 보입니다.
- 도움말에는 아이콘이 없습니다. 상태를 알릴 때만 안내(`info`) · 성공(`success`) · 오류(`error`)를 씁니다.
- 오류가 나면 같은 자리에 오류 메시지를 보여 줍니다. 비활성 칸의 도움말은 흐린 색입니다.
- 도움말은 선택 필드 설명으로 화면 낭독기가 함께 읽습니다.

## 상태

<Canvas of={Showcase.States} />

- 마우스를 올리면 모양이 바뀌고, 키보드 포커스를 받으면 테두리가 진해집니다.
- 목록을 펼치면 테두리가 강조되고 화살표가 위를 향합니다.
- `invalid`이면 오류 테두리로 표시합니다. 키보드 포커스를 받아도 오류 테두리가 유지됩니다.
- `disabled`이면 고를 수 없습니다.
- `readOnly`이면 화살표 없이 값만 보이고 목록이 펼쳐지지 않습니다.
- 고를 수 없는 옵션은 `SelectOption`의 `disabled` 또는 `Select`의 `disabledKeys`로 지정합니다.
- 목록은 선택 필드 아래에 같은 너비로 펼쳐집니다. 아래 공간이 부족하면 위로 펼쳐지고, 옵션이 많으면 목록 안에서 스크롤됩니다.

## 사용 예시

<Source
  language="tsx"
  code={`import { Select, SelectOption } from 'platform-design-system';

<Select label="과일" name="fruit" placeholder="과일 선택">
  <SelectOption id="apple">사과</SelectOption>
  <SelectOption id="banana">바나나</SelectOption>
  <SelectOption id="cherry" disabled>체리 (품절)</SelectOption>
</Select>

// 제어 컴포넌트 (값 = 옵션 id)
const [region, setRegion] = useState<Key | null>(null);
<Select label="지역" value={region} onChange={setRegion} invalid={!region} message={!region ? '지역을 선택하세요.' : undefined}>
  …
</Select>

// 필수 선택 — 라벨 뒤에 점
<Select label="부서" name="department" required>
  …
</Select>

// 데이터로 옵션 만들기
<Select label="국가" items={countries}>
  {(c) => <SelectOption id={c.code}>{c.name}</SelectOption>}
</Select>`}
/>

## 접근성

- `label`이 없으면 `aria-label`로 이름을 꼭 붙입니다.
- `readOnly`이면 화면 낭독기에 읽기 전용이라는 설명을 함께 전달합니다.
- `required`이면 화면 낭독기에 "필수"라는 설명을 제공합니다. `name`을 지정하면 폼 제출 시 선택 여부도 검사합니다.
- 키보드로 이렇게 조작합니다.

| 키 | 동작 |
| --- | --- |
| Enter · Space · ↓ · ↑ | 목록 펼치기 |
| ↓ · ↑ · Home · End | 옵션 이동 (고를 수 없는 옵션은 건너뜀) |
| 글자 입력 | 그 글자로 시작하는 옵션으로 이동 |
| Enter · Space | 고르고 목록 닫기 |
| Esc · Tab | 고르지 않고 목록 닫기 |

## 사용 규칙

- 값은 선택한 옵션의 `id`입니다. 아무것도 고르지 않았으면 `null`입니다.
- `value` · `onChange`로 값을 직접 관리하거나, `defaultValue`로 초깃값만 정합니다.
- `name`을 주면 폼을 보낼 때 선택값이 함께 전송되고 `required` 검사도 됩니다.
- `className` · `style`은 바깥 요소에 적용됩니다. 선택 필드 너비를 정하면 목록도 같은 너비로 펼쳐집니다.
