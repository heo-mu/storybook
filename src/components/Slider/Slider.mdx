# Slider

정해진 범위 안에서 숫자 값을 고르는 슬라이더입니다. 옆의 숫자 입력 칸에 값을 직접 입력할 수도 있습니다.

<Canvas of={Showcase.Overview} />

## 언제 사용하나요

- 인원 · 투명도처럼 최솟값과 최댓값이 정해진 숫자를 고를 때 사용합니다.

## 종류

- 범위는 `minValue` · `maxValue`로 정합니다. 기본은 0부터 100까지입니다.
- 값 사이 간격은 `step`으로 정합니다. 기본은 1입니다.
- `showInput`을 켜면 오른쪽에 숫자 입력 칸이 보입니다. 기본은 켜짐입니다.
- `unit`을 주면 숫자 입력 칸 오른쪽과 값 라벨에 단위가 붙습니다.
- `valueLabel`을 켜면 손잡이 위에 현재 값이 보입니다. 기본은 켜짐입니다.
- 숫자 형식은 `formatOptions`로 바꿉니다.

## 상태

<Canvas of={Showcase.States} />

- 마우스를 올리거나 드래그하거나 키보드로 선택하면 손잡이 위에 값 라벨이 보입니다.
- 드래그하는 동안 손잡이 주위에 반투명한 원이 보입니다.
- 키보드로 선택하면 손잡이에 포커스 테두리가 보입니다.
- `disabled`이면 값을 바꿀 수 없습니다.

## 접근성

- 화면에 보이는 라벨이 없으므로 `aria-label` 또는 `aria-labelledby`로 이름을 꼭 붙입니다.
- 숫자 입력 칸의 이름은 `inputLabel`로 정합니다. 기본은 `값 입력`입니다.
- 키보드로 이렇게 조작합니다.

| 키 | 동작 |
| --- | --- |
| ← · → · ↑ · ↓ | 한 `step`만큼 이동 |
| Page Up · Page Down | 크게 이동 |
| Home · End | 최솟값 · 최댓값으로 이동 |
| 숫자 입력 칸에서 ↑ · ↓ | 한 `step`만큼 이동 |

## 주의사항

- `onChange`는 값이 바뀌는 동안 계속 호출됩니다. 저장처럼 한 번만 할 일은 `onChangeEnd`에서 처리합니다.
- `onChangeEnd`는 드래그를 마치거나, 키를 누르거나, 숫자 입력 칸의 값을 확정할 때 호출됩니다.
- 숫자 입력 칸의 값은 Enter를 누르거나 다른 곳을 선택하면 확정됩니다. 범위를 벗어난 값은 범위 안으로, `step`에 맞게 바뀝니다.
