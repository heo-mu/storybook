# Stepper

여러 단계로 이루어진 과정의 현재 위치와 진행 상태를 표시합니다. 단계 이동 버튼으로 사용하지 않습니다.

<Canvas of={Showcase.Overview} />

## 사용 시점

- 가입 절차처럼 여러 단계를 차례로 거치는 과정에서 진행 상황을 보여 줄 때 씁니다.

## 종류

- 방향은 `orientation`(`horizontal` · `vertical`)으로 고릅니다. 기본은 `horizontal`입니다.
- 단계마다 제목 `label`과 설명 `description`을 붙일 수 있습니다.
- 단계 수에는 제한이 없습니다.

## 상태

<Canvas of={Showcase.IndicatorMatrix} />

| 단계 상태 | 뜻 |
| --- | --- |
| `completed` | 끝난 단계. 체크 아이콘이 보입니다 |
| `current` | 현재 단계 |
| `upcoming` | 진행 예정 단계 |
| `locked` | 잠긴 단계 |
| `error` | 오류가 있는 단계. 경고 아이콘이 보입니다 |

- 단계 상태는 `currentStep`에 따라 정해집니다. 앞 단계는 `completed`, 뒤 단계는 `upcoming`입니다.
- 잠김 · 오류는 단계의 `status`로 직접 정합니다.
- 완료된 단계 뒤의 연결선은 완료 모양으로 바뀝니다.
- 단계를 옮기면 연결선이 한 단계씩 채워지며 현재 단계가 이동합니다. 여러 단계를 건너뛰면 차례로 채워지고, 이전 단계로 가면 거꾸로 비워집니다. 동작 줄이기를 켜면 바로 바뀝니다.

## 사용 예시

<Source
  language="tsx"
  code={`import { Stepper } from 'platform-design-system';

<Stepper
  aria-label="가입 절차"
  currentStep={step}          // 0부터 셉니다 — 앞 단계는 완료, 뒤 단계는 예정
  steps={[
    { label: '약관 동의', description: '필수 항목' },
    { label: '정보 입력', description: '이름 · 연락처', status: hasError ? 'error' : undefined },
    { label: '완료' },
  ]}
/>

<Stepper orientation="vertical" steps={steps} currentStep={2} />`}
/>

- `currentStep`은 0부터 셉니다.
- 가로 Stepper에 너비를 주면 연결선이 남는 폭을 채웁니다. 세로 연결선은 길이가 정해져 있습니다.

## 접근성

- `aria-label`로 과정 이름(예: "가입 절차")을 붙이면 화면 낭독기가 무엇의 단계인지 알려 줍니다.
- 화면 낭독기는 각 단계를 "2단계, 완료"처럼 번호와 상태를 함께 읽습니다. 색과 아이콘으로만 보이는 상태도 말로 전달됩니다.
- 현재 단계는 화면 낭독기에 현재 단계로 알려집니다.

## 사용 규칙

- 라벨은 단계 아이콘을 기준으로 정렬되며 아이콘보다 넓게 표시될 수 있습니다.
- 가로 Stepper는 양 끝 글자가 잘리지 않도록 바깥에 글자 폭의 절반만큼 여백을 둡니다.
