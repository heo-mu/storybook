# Switch

알림·자동 저장 등 두 상태를 갖는 설정을 켜거나 끕니다.

<Canvas of={Showcase.Overview} />

## 사용 시점

- 알림 받기 · 자동 저장처럼 켜거나 끄는 설정에 사용합니다.

## 종류

- 켜짐은 `checked` · `defaultChecked`로 정합니다.
- 크기는 `size`(`sm` · `md`)로 고릅니다. 기본은 `sm`입니다.
- `label`을 빼면 스위치만 보입니다.

## 상태

<Canvas of={Showcase.States} />

- 마우스를 올리거나 누르면 모양이 바뀝니다.
- `disabled`이면 누를 수 없고 키보드 포커스를 받지 않습니다.
- 키보드 포커스를 받으면 스위치 둘레에 포커스 테두리가 보입니다.

## 움직임

<Canvas of={Showcase.Interaction} />

- 누르는 동안 스위치가 살짝 줄어들고, 손을 떼면 원래 크기로 돌아옵니다. 누른 채로 포인터가 스위치 밖으로 나가도 돌아옵니다. Space를 누르고 있는 동안도 같습니다.
- 켜거나 끄면 썸이 반대쪽 끝으로 미끄러지듯 움직여 튕김 없이 멈추고, 트랙 색도 함께 바뀝니다. 멈춘 모습은 디자인과 같습니다.
- 빠르게 여러 번 눌러도 썸은 지금 있는 자리에서 방향을 바꾸고, 마지막으로 누른 상태에서 멈춥니다. `checked`를 밖에서 바꿔도 같은 움직임으로 바뀝니다.
- 비활성 스위치는 반응하지 않습니다.
- 운영체제에서 움직임 줄이기를 설정하면 스위치가 줄어들지 않고, 썸과 색이 바로 바뀝니다.

## 사용 예시

<Source
  language="tsx"
  code={`import { Switch } from 'platform-design-system';

<Switch label="알림 받기" name="notify" defaultChecked />

// 제어 컴포넌트
<Switch label="자동 저장" checked={autoSave} onChange={(e) => setAutoSave(e.target.checked)} size="md" />`}
/>

## 접근성

- `label`이 없으면 `aria-label`로 이름을 꼭 붙입니다.
- Space 키로 켜고 끕니다. 화면 낭독기에는 "켜짐" 또는 "꺼짐"으로 전달됩니다.

## 사용 규칙

- 나머지 `<input>` 속성과 `ref`는 실제 스위치에 전달되고, `className` · `style`은 라벨을 포함한 바깥 요소에 적용됩니다.
