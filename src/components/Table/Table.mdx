# Table

표는 여러 항목의 데이터를 행과 열로 보여 줍니다. 한 항목의 속성은 키-값 표로 보여 줍니다.

<Canvas of={Showcase.Overview} />

## 언제 사용하나요

| 컴포넌트 | 쓰임 |
| --- | --- |
| `Table` | 설비 목록처럼 여러 항목을 비교하고 선택 · 정렬 · 행 열기가 필요할 때 |
| `KeyValueTable` | 설비 상세처럼 한 항목의 속성을 이름과 값으로 보여 줄 때 |

## 종류

### 데이터 표

| 컴포넌트 | 쓰임 |
| --- | --- |
| `TableColumn` | 열 머리글. `info`를 주면 도움말 아이콘, `allowsSorting`을 주면 정렬 아이콘이 붙습니다. |
| `TableSelectionColumn` · `TableSelectionCell` | 전체 선택 · 행 선택 체크박스 칸 |
| `TableEmptyColumn` | 제목이 보이지 않는 열(예: 편집 아이콘 열) |
| `TableCell` | 본문 칸. `variant`로 보통 글자(`text`)와 굵은 글자(`strong`)를 고릅니다. |
| `TableDragHandle` | 행을 끌어서 순서를 바꾸는 손잡이 |

- 배지 · 버튼 · 스위치 · 아이콘이 필요하면 `TableCell` 안에 그 컴포넌트를 넣습니다.

### 키-값 표

<Canvas of={TableStories.KeyValue} />

- `KeyValueTable` 안에 `KeyValueItem`을 넣습니다. `label`이 이름, 내용이 값입니다.
- `required`를 주면 이름 뒤에 빨간 점이 붙습니다.
- `editable`을 주면 값을 바로 고칠 수 있는 편집 칸이 됩니다(아래 사용 방법 참고).

## 상태

- `onRowAction`이 있으면 행을 누를 수 있고, 마우스를 올리거나 누르면 행 배경이 바뀝니다.
- 선택된 행은 배경 강조 없이 체크박스로만 표시합니다.
- 정렬 중인 열은 정렬 아이콘 색이 바뀝니다.
- 키보드로 선택하면 행 · 칸 · 머리글 안쪽에 포커스 테두리가 보입니다.
- 편집 칸은 평소에는 글자처럼 보이고, 마우스를 올리거나 편집하는 동안 입력 상자가 나타납니다.
- `KeyValueItem`의 `disabled`는 칸 배경을 비활성으로 바꿉니다. 안의 입력 컴포넌트에는 `disabled`를 따로 줍니다.

## 사용 방법

<Source
  language="tsx"
  code={`import { Table, TableHeader, TableColumn, TableSelectionColumn, TableBody, TableRow, TableCell, TableSelectionCell } from 'platform-design-system';

<Table aria-label="설비 목록" selectionMode="multiple" onRowAction={(id) => open(id)}
  sortDescriptor={sort} onSortChange={setSort}>
  <TableHeader>
    <TableSelectionColumn />
    <TableColumn id="name" isRowHeader allowsSorting>설비명</TableColumn>
    <TableColumn id="site" info="설비가 설치된 건물">위치</TableColumn>
  </TableHeader>
  <TableBody items={rows}>
    {(row) => (
      <TableRow id={row.id}>
        <TableSelectionCell />
        <TableCell variant="strong">{row.name}</TableCell>
        <TableCell>{row.site}</TableCell>
      </TableRow>
    )}
  </TableBody>
</Table>

<KeyValueTable>
  <KeyValueItem label="설비명" required>1호기 공조</KeyValueItem>
  <KeyValueItem label="상태"><Badge size="md" dot={false}>운영</Badge></KeyValueItem>
</KeyValueTable>`}
/>

### 편집 칸

값 칸에 입력 컴포넌트를 넣고 `editable`을 주면 편집 칸이 됩니다. `unit`은 값 뒤에 붙는 단위 글자입니다.

<Source
  language="tsx"
  code={`<KeyValueTable>
  <KeyValueItem label="정격 용량" editable unit="kW"><Input size="sm" aria-label="정격 용량" /></KeyValueItem>
  <KeyValueItem label="종류" editable><Select size="sm" aria-label="종류">…</Select></KeyValueItem>
  <KeyValueItem label="점검 기간" editable>
    <DatePicker size="sm" aria-label="시작일" /><span className="ds-kv__unit">~</span><DatePicker size="sm" aria-label="종료일" />
  </KeyValueItem>
  <KeyValueItem label="유형">
    <KeyValueGroup><FilterChip size="md" selected>선택유형: 옵션명, 옵션명</FilterChip><TextButton rightIcon={<ArrowCounterClockwiseIcon />}>초기화</TextButton></KeyValueGroup>
  </KeyValueItem>
  <KeyValueItem label="사용"><Switch size="md" aria-label="사용" /><span className="ds-kv__hint">설명</span></KeyValueItem>
  <KeyValueItem label="대표 이미지" stack>
    <KeyValueGroup><Button variant="tertiary" appearance="outline" size="xs" style={{ minWidth: 80 }}>파일 선택</Button>
      <span className="ds-kv__hint">권장 비율 1:1, JPG/PNG, 최대 5MB</span></KeyValueGroup>
    <ImageUploadPreview src={url} alt="대표 이미지" onRemove={…} />
  </KeyValueItem>
</KeyValueTable>`}
/>

| 값 종류 | 넣는 컴포넌트 |
| --- | --- |
| 글자 · 전화번호 · 여러 줄 글자 | `Input size="sm"` |
| 선택 | `Select size="sm"` |
| 날짜 · 기간 | `DatePicker size="sm"`. 기간은 두 개 사이에 `~`를 둡니다. |
| 필터 | `FilterChip size="md"`. 여러 값을 목록에서 고르려면 `FilterChipSelect`를 씁니다. 값이 있으면 초기화 `TextButton`을 `KeyValueGroup`에 함께 넣습니다. |
| 스위치 | `Switch size="md"`와 안내 글자(`ds-kv__hint`) |
| 파일 첨부 | `stack`을 주고 파일 선택 버튼 · 안내 글자와 `ImageUploadPreview`를 넣습니다. |

## 접근성

- `Table`에는 `aria-label`로 표 이름을 붙입니다.
- 키보드 화살표로 칸 사이를 이동할 수 있습니다.
- 정렬 방향은 화면 낭독기에 전달됩니다.
- `TableEmptyColumn`에는 `aria-label`로 열 이름을 붙입니다. 화면에는 보이지 않고 화면 낭독기만 읽습니다.
- 아이콘만 있는 칸은 아이콘에 `aria-label`로 이름을 붙입니다. 누를 수 있게 하려면 버튼으로 감쌉니다.
- `required`의 빨간 점은 화면 낭독기가 "필수"로 읽습니다.
