## 관리 모드 (table_value_editable)

값 칸에 실제 입력 컴포넌트를 넣고 `editable`을 주면, 평소에는 테두리 없이 글자처럼 보이고(Default) 마우스를 올리거나
편집 중일 때 입력 상자가 나타납니다(Hover · Editing). `disabled`는 칸 배경, `unit`은 뒤 단위 글자입니다.

## 코드 정책 (Figma에서 정해지지 않은 부분)

- **관리 모드 상태**: Figma는 칸 단위 상태(Default · Hover · Editing)이므로 칸에 마우스가 있거나 포커스 · 열린 목록이 있으면
  입력 상자를 보여 줍니다. Hover에서는 Figma처럼 입력 상자의 기본(Default · Completed) 테두리를 씁니다.
- **Textarea 유형**: Figma는 편집 시 한 줄 Input을 쓰면서 채워진 값은 두 줄로 그려 둘을 함께 구현할 수 없습니다. 한 줄 Input으로 구현했고
  두 줄 변형 3개는 수동 검토 대상입니다(figma-issues F58).
- **안내 글자 색**: Figma `table/key-value/value/label/hover`는 토큰 스냅샷 이후 추가된 변수라 같은 값의 `text/tertiary`를 씁니다(F57).
- **행 Hover · Pressed 색**: Figma 예시는 의미 변수(`fill/secondary/subtle/hover`)에 직접 바인딩했지만 같은 용도의 컴포넌트 변수
  `table/data/background/hover · pressed`가 있어 그것을 씁니다(figma-issues F54).
- **선택된 행**: Figma에 별도 모습이 없어 체크박스로만 표시합니다.
- **정렬 방향 아이콘**: Figma는 CaretUpDown 하나라 방향은 `aria-sort`로 전달하고 아이콘은 활성 색만 바뀝니다.
- **편집 아이콘(Type Icon)**: Figma에는 아이콘만 있습니다. 누를 수 있게 하려면 버튼으로 감싸고 이름을 주세요.
