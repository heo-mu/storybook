# Tabs

Tabs는 한 화면의 내용을 몇 갈래로 나누고, 탭을 눌러 바꿔 보게 합니다.

<Canvas of={Showcase.Overview} />

## 언제 사용하나요

- 주문 상태처럼 같은 화면 안에서 내용을 나눠 보여 줄 때 씁니다.
- `Tabs` 안에 탭 목록 `TabList`와 탭 `Tab`, 탭마다 내용 `TabPanel`을 넣습니다.

## 종류

| `appearance` | 모양 |
| --- | --- |
| `line` (기본) | 탭 아래로 선이 이어지고, 선택된 탭의 밑줄이 강조됩니다 |
| `filled` | 탭마다 배경이 있고, 선택된 탭의 배경이 강조됩니다 |

- `variant`(`primary` · `secondary`)로 선택된 탭의 색을 고릅니다.
- 크기는 `size`(`sm` · `md` · `lg`)로 고릅니다. 기본은 `sm`입니다.
- `filled` 탭은 `shape`(`square` · `rounded`)로 모서리 모양을 고릅니다.
- 탭은 간격 없이 나란히 놓입니다.

## 상태

<Canvas of={Showcase.States} />

- 마우스를 올리거나 누르면 모양이 바뀝니다.
- 선택된 탭은 선택됨 모양으로 보입니다.
- `Tab`의 `disabled`이면 고를 수 없고, 방향키로 옮길 때도 건너뜁니다.
- 키보드로 선택하면 탭과 탭 패널에 포커스 테두리가 보입니다.

## 사용 방법

<Source
  language="tsx"
  code={`import { Tabs, TabList, Tab, TabPanel } from 'platform-design-system';

<Tabs appearance="line" selectedKey={tab} onSelectionChange={setTab}>
  <TabList aria-label="주문 상태">
    <Tab id="all">전체</Tab>
    <Tab id="paid">결제 완료</Tab>
    <Tab id="canceled" disabled>취소</Tab>
  </TabList>
  <TabPanel id="all">…</TabPanel>
  <TabPanel id="paid">…</TabPanel>
  <TabPanel id="canceled">…</TabPanel>
</Tabs>

// 채운 둥근 탭 (Secondary · md)
<Tabs appearance="filled" shape="rounded" variant="secondary" size="md">…</Tabs>`}
/>

- `Tab`과 `TabPanel`은 같은 `id`로 짝을 짓습니다.
- 처음 선택할 탭은 `defaultSelectedKey`로 정합니다. 선택을 바깥에서 관리하려면 `selectedKey`와 `onSelectionChange`를 씁니다.
- `TabPanel`에는 따로 꾸밈이 없습니다. 내용의 여백 등은 직접 정합니다.

## 접근성

- `TabList`에는 `aria-label`로 탭 목록의 이름을 붙입니다.
- ← → 방향키로 탭을 옮기고, Home · End로 처음과 끝 탭으로 갑니다.
- 방향키로 옮기면 바로 선택됩니다. 내용이 무거우면 `keyboardActivation="manual"`로 바꿔 Enter · Space를 눌러야 선택되게 합니다.
