# Textarea

여러 줄 글자를 입력받는 입력 칸입니다. 최대 글자 수를 정하면 지금까지 입력한 글자 수가 함께 보입니다.

<Canvas of={Showcase.Overview} />

## 언제 사용하나요

- 요청 사항 · 사유처럼 여러 줄로 길게 입력받을 때 사용합니다.
- 한 줄만 입력받을 때는 `Input`을 사용합니다.

## 종류

- 크기는 `size`(`sm` · `md`)로 고릅니다. 기본은 `sm`입니다.
- `maxLength`를 정하면 오른쪽 아래에 `입력한 글자 수/최대 글자 수`가 보입니다. 숨기려면 `showCount={false}`로 끕니다.
- `message`를 넣으면 입력 칸 아래에 도움말 메시지가 보입니다. 메시지 종류는 `messageType`(`info` · `success` · `error`)으로 고릅니다.

## 상태

<Canvas of={Showcase.States} />

- 마우스를 올리거나 키보드로 선택하면 테두리가 바뀝니다.
- `invalid`이면 오류 테두리로 표시합니다.
- `disabled`이면 입력할 수 없고, `readOnly`이면 값을 볼 수만 있습니다.

## 사용 방법

<Source
  language="tsx"
  code={`import { Textarea } from 'platform-design-system';

<Textarea label="요청 사항" name="memo" maxLength={100} placeholder="내용 입력" />

<Textarea label="사유" value={reason} onChange={(e) => setReason(e.target.value)}
  maxLength={200} invalid={reason.length < 10} message={reason.length < 10 ? '10자 이상 입력하세요.' : undefined} />`}
/>

## 접근성

- `label`이 없으면 `aria-label`로 이름을 꼭 붙입니다.
- 도움말 메시지와 글자 수는 입력 칸 설명으로 화면 낭독기가 함께 읽습니다.

## 주의사항

- 입력 칸 높이는 고정되어 있습니다. 내용이 넘치면 입력 칸 안에서 스크롤되고, 크기를 조절하는 손잡이는 없습니다.
- `maxLength`보다 길게는 입력되지 않습니다.
- 나머지 `<textarea>` 속성과 `ref`는 실제 입력 칸에 전달되고, `className` · `style`은 바깥 요소에 적용됩니다.
