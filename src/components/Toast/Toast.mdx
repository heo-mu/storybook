# Toast

작업 결과를 화면 아래 오른쪽에 잠깐 알립니다. 5초 뒤 자동으로 닫히고, "닫기"로 바로 닫을 수 있습니다.

<Canvas of={Showcase.Overview} />

## 사용 시점

| 컴포넌트 · 함수 | 쓰임 |
| --- | --- |
| `ToastRegion` | 토스트가 나타나는 영역. 앱에 한 번만 둡니다. |
| `showToast()` · `closeToast()` | 어디서든 토스트를 띄우고 닫습니다. |
| `Toast` | 같은 모양을 페이지 안에 고정으로 그릴 때 씁니다. |

## 종류

| `status` | 쓰임 |
| --- | --- |
| `information` | 안내 |
| `success` | 성공 |
| `warning` | 주의 — 작업은 계속할 수 있지만 확인이 필요할 때 |
| `error` | 오류 — 작업을 막는 문제 |

- 종류마다 테두리와 아이콘 색이 다릅니다.
- 제목(메시지) 아래에 `description`으로 짧은 설명을 붙일 수 있습니다. 제목만 있으면 40px, 설명이 있으면 54px 높이입니다.
- 종류 아이콘은 `showIcon={false}`로 뺄 수 있습니다.
- 오른쪽 "닫기" 버튼은 글자와 원형 X 아이콘이 있는 텍스트 버튼입니다. `ToastRegion`의 토스트에는 항상 있고, 고정 `Toast`는 `showClose`로 정합니다.

## 사용 예시

<Source
  language="tsx"
  code={`import { ToastRegion, showToast, closeToast } from 'platform-design-system';

// 앱에 한 번
<ToastRegion />

// 어디서든
showToast('저장했습니다', { status: 'success' });
showToast('저장하지 못했습니다', { status: 'error', description: '네트워크 연결을 확인하세요' });

// 닫을 때까지 유지하고 코드에서 닫기: showToast가 돌려준 key
const key = showToast('업로드 중입니다', { timeout: null });
closeToast(key);`}
/>

## 사용 규칙

- 토스트는 화면 아래 오른쪽에 나타나고, 새 토스트가 아래에 붙으면서 먼저 온 토스트가 위로 밀려 올라갑니다.
- 모든 종류가 5초 뒤 자동으로 닫힙니다. `timeout`(ms)은 5000보다 짧게 정할 수 없고, `null`이면 닫을 때까지 남습니다.
- 마우스를 올리거나 키보드 포커스가 있는 동안에는 자동으로 닫히지 않습니다.
- 한 번에 3개까지 보입니다. 네 번째 토스트가 오면 가장 오래된 토스트가 밀려 나가 사라집니다.
- 같은 문구와 종류를 다시 보내면 겹쳐 쌓지 않고 새로 바꿔 보여 줍니다.
- 제목과 설명은 각각 한 줄로 보이며, 길면 말줄임(…)으로 잘립니다.
- 위치는 `ToastRegion`의 `className`으로 바꿀 수 있습니다. 토스트는 `showToast()` · `closeToast()`로만 다루고, `toastQueue`는 내부용이므로 직접 쓰지 않습니다.

## 접근성

- 토스트가 나타나면 화면 낭독기가 제목과 설명을 읽어 줍니다.
- Tab으로 토스트와 "닫기" 버튼 사이를 이동하고, "닫기"에서 Enter 또는 Space를 누르면 닫힙니다.
- "닫기" 버튼의 낭독 이름은 "알림 닫기"이며 `closeLabel`로 바꿀 수 있습니다.
