# Toast — 사용 가이드

Figma **Toast** 프레임(91:5557)의 `toast`(3개)를 구현했습니다. 잠시 나타났다 사라지는 알림입니다(화면에 머무는 안내는 Alert).

<Canvas of={Showcase.Overview} />

## 사용 예

<Source
  language="tsx"
  code={`import { ToastRegion, showToast } from 'platform-design-system';

// 앱에 한 번
<ToastRegion />

// 어디서든
showToast('저장했습니다', { status: 'success' });
showToast('저장하지 못했습니다', { status: 'error', timeout: null }); // 닫을 때까지 유지`}
/>

## Figma 속성 → Props

| Figma | Prop | 비고 |
| --- | --- | --- |
| Status Information · Success · Error | `status` | 테두리 · 아이콘 색 |
| Alert Text | 메시지(`showToast` 첫 인자 / `children`) | 한 줄, 넘치면 말줄임 |
| Close Icon | `showClose`(정적 `Toast`), 영역의 토스트는 항상 닫기 버튼 | 이름 "알림 닫기" |

## 코드 정책 (Figma에 정의되지 않은 부분)

- **표시 위치 · 간격**: Figma에 없어 화면 아래 가운데(아래 여백 `p-5`), 토스트 사이 `m-2`로 두었습니다. `className`으로 바꿀 수 있습니다
  (figma-issues F44 — 디자인 확인 필요).
- **자동으로 닫히는 시간**: 기본 5초(읽을 시간을 위해 최소 5초), `timeout: null`이면 닫을 때까지 유지. 마우스를 올리거나
  포커스가 있는 동안에는 멈춥니다.
- **긴 메시지**: Figma 높이가 36px 고정이라 한 줄로 두고 말줄임합니다.
- **react-aria Toast**: react-aria-components 1.22에서 UNSTABLE API입니다. 이 패키지의 `ToastRegion` · `showToast`가 감싸므로
  라이브러리가 바뀌어도 사용하는 쪽 코드는 그대로입니다.
