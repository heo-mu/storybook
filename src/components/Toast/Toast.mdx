# Toast

토스트는 화면 아래에 잠시 나타났다 사라지는 알림입니다. 화면에 계속 머무는 안내는 알림(Alert)을 씁니다.

<Canvas of={Showcase.Overview} />

## 언제 사용하나요

| 컴포넌트 · 함수 | 쓰임 |
| --- | --- |
| `ToastRegion` | 토스트가 나타나는 영역. 앱에 한 번만 둡니다. |
| `showToast()` · `closeToast()` | 어디서든 토스트를 띄우고 닫습니다. |
| `Toast` | 같은 모양을 페이지 안에 고정으로 그릴 때 씁니다. |

## 종류

| `status` | 쓰임 |
| --- | --- |
| `information` | 안내 |
| `success` | 성공 |
| `error` | 오류 |

- 종류마다 테두리와 아이콘 색이 다릅니다.
- `ToastRegion`의 토스트에는 항상 닫기 버튼이 있습니다. 고정 `Toast`는 `showClose`로 정합니다.

## 사용 방법

<Source
  language="tsx"
  code={`import { ToastRegion, showToast, closeToast } from 'platform-design-system';

// 앱에 한 번
<ToastRegion />

// 어디서든
showToast('저장했습니다', { status: 'success' });
showToast('저장하지 못했습니다', { status: 'error', timeout: null }); // 닫을 때까지 유지

// 코드에서 닫기: showToast가 돌려준 key
const key = showToast('업로드 중입니다', { timeout: null });
closeToast(key);`}
/>

## 주의사항

- 안내 · 성공은 5초 뒤 자동으로 닫힙니다. 오류는 사용자가 닫을 때까지 남습니다.
- `timeout`(ms)은 5000보다 짧게 정할 수 없습니다. `null`이면 닫을 때까지 남습니다.
- 마우스를 올리거나 키보드로 선택한 동안에는 자동으로 닫히지 않습니다.
- 한 번에 3개까지 보입니다. 더 많으면 새 토스트가 보이고, 오래된 토스트는 기다렸다가 앞의 토스트가 닫히면 다시 나타납니다.
- 같은 문구와 종류를 다시 보내면 겹쳐 쌓지 않고 새로 바꿔 보여 줍니다.
- 메시지는 한 줄로 보이며, 길면 말줄임(…)으로 잘립니다.
- 토스트는 화면 아래 가운데에 나타납니다. 위치는 `ToastRegion`의 `className`으로 바꿀 수 있습니다.
- 토스트는 `showToast()` · `closeToast()`로만 다룹니다. `toastQueue`는 내부용이므로 직접 쓰지 않습니다.

## 접근성

- 토스트가 나타나면 화면 낭독기가 읽어 줍니다.
- Tab으로 토스트와 닫기 버튼 사이를 이동하고, 닫기 버튼에서 Enter 또는 Space를 누르면 닫힙니다.
- 닫기 버튼 이름은 "알림 닫기"이며 `closeLabel`로 바꿀 수 있습니다.
