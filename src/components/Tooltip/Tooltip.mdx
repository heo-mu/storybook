# Tooltip

요소에 마우스를 올리거나 키보드 포커스를 두면 짧은 보충 설명을 표시합니다.

<Canvas of={Showcase.Overview} />

## 사용 시점

- 버튼이나 아이콘이 무엇을 하는지 짧게 설명할 때 씁니다.

## 종류

- `placement`로 툴팁이 나타날 쪽을 고릅니다: `top` · `right` · `bottom` · `left`. 공간이 없으면 반대쪽에 나타납니다.
- 화살표는 `showArrow={false}`로 숨길 수 있습니다.

## 상태

- 마우스를 올리면 0.5초 뒤에 나타납니다. 시간은 `delay`로 바꿀 수 있습니다.
- 키보드 포커스를 받으면 바로 나타납니다.
- 마우스나 포커스가 떠나거나 Esc를 누르면 닫힙니다. 닫히기까지의 시간은 `closeDelay`로 바꿀 수 있습니다.

## 사용 예시

<Source
  language="tsx"
  code={`import { Button, IconButton, Tooltip } from 'platform-design-system';

<Tooltip content="변경 사항을 저장합니다">
  <Button>저장</Button>
</Tooltip>

<Tooltip content="설정" placement="bottom">
  <IconButton aria-label="설정" icon={<GearIcon />} />
</Tooltip>`}
/>

- 툴팁을 띄울 요소를 `Tooltip`으로 감싸고, 설명은 `content`에 넣습니다.

## 접근성

- 툴팁 글자는 감싼 요소의 설명으로 화면 낭독기가 읽습니다.
- Tab으로 요소에 포커스를 두면 툴팁이 나타나고, Esc로 닫습니다.

## 사용 규칙

- 감싸는 요소는 ref와 props를 전달하는 컴포넌트여야 합니다. `Button` · `IconButton` · `TextButton` · `Link`를 쓸 수 있습니다.
