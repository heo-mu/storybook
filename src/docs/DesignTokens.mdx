# Design Tokens

색·타이포그래피·간격 등 반복해서 사용하는 디자인 값을 CSS 변수로 제공합니다. 컴포넌트와 화면에 같은 토큰을 사용해 시각적 일관성을 유지합니다.

## 사용 예시

- `platform-design-system/styles.css`를 불러오면 모든 토큰을 쓸 수 있습니다. 토큰만 필요하면 `platform-design-system/tokens.css`를 불러옵니다.
- 이름은 Figma 변수 이름의 `/`를 `-`로 바꾼 것입니다. 예: `colors/text/primary` → `--colors-text-primary`
- CSS에서는 `var(--colors-text-primary)`처럼 씁니다.

## 토큰 단계

| 단계 | 내용 |
| --- | --- |
| Primitive | 색 팔레트 · 간격 · 글자 크기 같은 기본 값 |
| Theme | 브랜드 색 같은 테마 값 |
| Semantic | 텍스트 색 · 배경 색처럼 쓰임에 따라 이름 붙인 값 |
| Component | 특정 컴포넌트에만 쓰는 값 |

- Primitive를 기반으로 Theme, Semantic, Component 순서로 용도에 맞는 값을 정의합니다. 가능한 한 사용 목적이 드러나는 Semantic 또는 Component 토큰을 선택합니다.
